# 内置头像

100 张原创头像均使用内置 `image_gen.imagegen` 工具逐张生成，共 100 次独立生成调用。没有使用 CLI/API 回退、拼图切片、程序绘图或复制凑数。

- 使用文件：`avatar-001.webp` 至 `avatar-100.webp`。
- 头像规格：256×256 WebP，质量 86，Lanczos 缩小，全部压缩图合计 905,308 字节。
- 选择列表：`manifest.json`，100 项 `{id, name, url}`。
- 完整提示词集合：`prompts.json`，包含每张头像的名称、主体和完整生成提示词。
- 来源及哈希：`provenance.json`，记录生成工具、原图和压缩图 SHA-256、原图尺寸及文件大小。
- 风格：暖奶油底色、克制蓝黄红与自然色、精致人物与动物/机器人/植物/幻想角色插画，单主体无文字。

生成原图为收藏保留，合计 219,763,892 字节；应用只使用 WebP 缩略图。原图不放进 Git 或安装包，已同时保存在本机：

1. 项目忽略目录 `dist-desktop/avatar-originals/`。
2. 持久收藏目录 `~/Pictures/Brclio Avatars/2026-10-12/`（不受构建目录清理影响）。

两个目录均包含 100 张 PNG 原图，以及本次生成的提示词和 provenance。最终校验确认 100 个唯一 ID、100 个压缩文件、100 份原图双份副本、256×256 WebP 规格，以及全部哈希一致。
