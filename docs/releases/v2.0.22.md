## 报价、订单与会员

- 套餐由产品后端实时读取支付中心目录。初始商品为日付 ¥3.00 / 1 天、月付 ¥19.90 / 30 天、年付 ¥69.90 / 365 天，均按次购买、不自动续费；实际价格以本次确认的目录为准。
- 目录与下单之间发生改价时，原请求不会打开收银台，需要确认新报价后创建新订单。每笔订单保留金额与实际会员规则快照，历史付款按创建时的承诺核对。
- 支付返回页与客户端成功提示只用于查询订单。只有正式环境付款通知通过验签、产品与金额核对，并持久保存后才开通权益；重复通知不会重复增加会员时长。
- 会员从当前时间与原到期时间的较晚者顺延，永久会员无需购买时长套餐。已有设备限制、主页批量下载及会员原视频规则继续适用；VIP 交流群独立收费，不属于这些套餐。
- 正式账号、订单、去重与审计记录继续存入现有 GitHub 私有业务仓库，没有新增数据库或迁移业务存储。长期支付凭证只在可信后端保存。
