# v2.0.4：升级代理控制与 Mac 安装提示修复

版本记录日期：2026 年 10 月 3 日（北京时间）。本版让用户已有的系统代理优先，并提供「关闭软件内置代理」按钮，同时修复 Mac 同版本重装清理和安装提示无法关闭的问题。

## 本次更新

- 已开启系统代理时，更新请求沿用系统网络，不启动软件内置代理，不更改系统代理设置。
- 默认仅在检查更新、应用内下载安装包或获取可信下载地址时使用内置升级代理。后台订阅配置决定使用的来源，安装包不内置默认订阅；每次需要代理时刷新后台配置和订阅，选择实测延迟最低的可用节点。
- 「关于软件」的升级区域和更新弹窗新增「关闭软件内置代理」。它能停止配置获取、订阅抓取、内核启动、测速及更新传输期间的内置代理会话，保留桌面已下载进度。
- 手动关闭状态持续保存，退出和重启软件、后台自动检查均保持停用。下次明确点击检查更新、下载更新或浏览器下载安装包时，已接受的新操作自动恢复内置代理资格；重复点击和被拒绝的请求不恢复。
- 检查、下载和下载地址获取完成、失败、取消或退出后关闭内置代理。本地安装不启动代理；外部浏览器的实际下载使用浏览器自己的网络设置。
- Mac 同版本重装时，有完整私有安装收据证明的临时旧版可以安全清理，历史已确认的清理记录也可在较新版本继续重试。
- Mac 新版已经启动、仅临时旧版清理失败时，安装窗口显示「安装已完成，清理待重试」，随后自动关闭。「关闭」按钮和左上角关闭按钮可随时关闭提示，不中断安装，不删除安装记录或恢复备份。

Android 同期发布 v1.0.11，采用相同的代理启停规则，并优先沿用系统 HTTP/PAC 代理或已开启的应用 VPN。
