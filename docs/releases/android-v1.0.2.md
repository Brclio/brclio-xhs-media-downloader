# Android v1.0.2：书籍与编程私教

2026 年 9 月 29 日更新，适用于 Android 8.0 及以上。Android 独立编号为 `1.0.2`，内部版本号为 `10002`；Mac / Windows 对应版本为 [v1.8.18](https://github.com/Brclio/brclio-xhs-media-downloader/releases/tag/v1.8.18)，各自沿用原更新通道。

## 本次更新

- 首页新增「书籍与编程私教」入口，介绍 AI悦创编著的《编程启蒙：思维与代码》与长期一对一编程教学。
- 教学面向小学至大学及留学生，涵盖 Vibe Coding、Python、Java、C++、少儿编程、算法、竞赛与课程辅导。
- 推广页和图片随安装包提供，可离线查看。打开独立页面后，返回仍保留下载页的输入、解析结果与当前任务。
- 微信联系图片仅保留二维码，可点击放大，或通过 Android 系统文件选择器保存 PNG。取消保存后可重新尝试；无法使用保存接口时提供放大截图入口。

## 在线更新

应用启动后自动检查独立 Android 发布，也可在「软件更新」区手动检查。选择更新后，应用下载 APK 并核对校验值、包名、版本及签名，再进入系统安装确认。首次更新可能需要按系统提示允许 Brclio 安装应用。

## 安装与校验

下载 [Brclio-XHS-Android-1.0.2-release.apk](https://github.com/Brclio/brclio-xhs-media-downloader/releases/download/android-v1.0.2/Brclio-XHS-Android-1.0.2-release.apk) 安装。正式包沿用固定 Android 密钥，可覆盖升级 v1.0.0 / v1.0.1；debug 测试包使用独立应用 ID，不会被正式包覆盖。

同名 `.apk.sha256` 与 `SHA256SUMS.txt` 提供文件校验值，`android-update.json` 记录版本、源码提交、APK 校验值和签名证书指纹。

Android 继续提供小红书单篇笔记解析、原图、实况素材、视频、文案、ZIP、系统保存与分享。解析需要联网，受原笔记公开可见性与平台访问限制影响；保存期间请保持应用打开。
