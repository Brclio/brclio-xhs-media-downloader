## 本次更新

### 更清晰的安装确认

- 改用应用内确认弹窗，突出当前版本、新版本以及“安装并重启”。
- 简洁说明任务保存、客户端替换和自动重开；系统安装要求放在可展开的详细说明中。
- “稍后安装”、Esc 和点击遮罩都可以取消。关闭窗口、界面异常或退出应用时也会取消未确认的安装。

### 成功升级后不保留旧客户端备份

- Mac 覆盖更新只在安装过程中临时保留旧应用，用于安装失败时恢复。
- 新客户端启动、窗口和必要服务就绪后，确认此次升级并清理对应的旧应用备份；不会仅凭系统接受启动请求就删除旧应用。
- 安装失败或无法安全确认备份归属时保留恢复文件，并记录结果；账号、任务记录和已下载媒体不受清理影响。
- 保留 v1.8.2 的更新包断点续传、可见安装进度与安装后自动重开。

## 升级说明

从旧客户端安装本版这一次，安装确认仍由旧客户端显示；新弹窗用于安装 v1.8.3 后的更新。新版启动时会处理旧更新器为此次成功升级生成的对应备份。

清理仅针对应用内更新器生成、有安装记录并能核对归属的旧客户端备份；不搜索删除用户另行复制的应用。Windows 安装版使用原有覆盖流程；便携版更新会转为 setup 安装版，原便携 EXE 不会被覆盖。手动从 Finder 拖放 DMG 应用仍需自行打开。

正常升级沿用原账号、任务记录和已下载文件。下载任务在重开后仍需手动继续。

## 验证与说明

发布流水线在 Mac arm64、Mac x64 和 Windows x64 上执行测试、打包、安装包源码比对、内置 Python 与真实 Electron 验证，全部成功后才公开本版本。各平台构建提交与安装包 SHA-256 见附件 `build-evidence.json` 和 `SHA256SUMS.txt`。
