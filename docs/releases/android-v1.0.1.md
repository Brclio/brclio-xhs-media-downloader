# Android v1.0.1：iPhone 快捷指令福利入口

2026 年 9 月 28 日更新，适用于 Android 8.0 及以上。Android 独立编号为 `1.0.1`，内部版本号为 `10001`；Mac / Windows 对应版本为 [v1.8.16](https://github.com/Brclio/brclio-xhs-media-downloader/releases/tag/v1.8.16)，各自沿用原更新通道。

## 本次更新

- 新增「iPhone 小红书无水印下载快捷指令」福利入口，与 Mac、Windows 客户端同步展示。
- 可点击访问 iCloud 快捷指令页面，也可复制完整链接，发送到自己的 iPhone 后打开并添加。
- Android 的单篇解析、原图、实况、视频、文案、ZIP、系统保存与分享继续使用原有入口。

快捷指令供 iPhone 使用。请在 Android 客户端的福利入口访问页面或复制链接，再发送到自己的 iPhone。

## 在线更新

应用启动后自动检查独立 Android 发布，也可在「软件更新」区手动检查。用户选择更新后，应用下载 APK 并核对校验值、包名、版本及签名，再进入系统安装确认。网络失败、取消或校验失败不会进入安装器。首次更新可能需要按系统提示允许 Brclio 安装应用。

## 安装与适用范围

下载 [Brclio-XHS-Android-1.0.1-release.apk](https://github.com/Brclio/brclio-xhs-media-downloader/releases/download/android-v1.0.1/Brclio-XHS-Android-1.0.1-release.apk) 安装；同名 `.apk.sha256` 和 `SHA256SUMS.txt` 提供校验值，`android-update.json` 提供构建版本与签名证书指纹。正式包由固定 Android 密钥签名，可覆盖升级 v1.0.0。此前的 debug 测试包使用独立应用 ID，不会被正式包覆盖。
