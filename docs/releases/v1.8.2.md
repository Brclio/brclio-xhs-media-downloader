## 本次更新

### 下载中断后，接着下载

- 更新安装包在网络中断、超时或手动暂停后保留已下载部分；重新打开软件后仍可继续下载。
- 更新页与弹窗显示保存的进度和“继续下载”，不再把每次失败都当成从零开始。
- 不同版本和校验值的缓存相互隔离，完成后校验整个安装包；服务器不支持续传时回退到完整下载，校验失败时重新下载。

### 覆盖安装，看得见进度

- Mac 使用独立安装进度窗口，显示打开安装包、校验、复制、覆盖和启动等实际阶段；旧软件退出后仍保持可见。
- Windows 显示安装程序的覆盖进度，等待旧客户端保存任务并退出后再继续安装。
- 安装成功后自动重新打开软件，无需再点击快捷方式；Windows 无需等到点击“完成”才启动。
- 安装期间正常退出会等待准备和交接完成，避免遗留停住的进度窗口。Mac 替换或启动请求失败时尝试恢复旧版本。

### 新版更新弹窗

- 集中显示版本号与可滚动的更新说明，底部固定“稍后再说”和“立即更新”。
- 弹窗内可以下载、暂停、继续和重试；选择“后台下载”后可以继续使用软件。
- 同一版本在本次打开软件期间只自动弹出一次，手动检查更新可以再次查看。
- 下载完成后点击“安装并重启”，确认后进入安装流程。

## 升级说明

断点续传和新弹窗需要先安装 v1.8.2 才能用于之后的更新，无法恢复旧客户端已删除的下载片段。Mac 的独立进度窗和自动重开用于应用内覆盖更新；从 Finder 手动拖放 DMG 内应用后仍需自行打开。Windows 便携版更新使用 setup 安装包，之后请使用新版快捷方式。

正常覆盖升级沿用原账号、任务记录和已下载文件。主页下载任务在重开后仍需手动继续。
