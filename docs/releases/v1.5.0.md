# v1.5.0 — Mac / Windows 本地版与主页批量下载

本地版保留网页版单篇笔记的图片、实况、视频、文案、复制和 ZIP 功能，新增小红书主页批量下载。安装包自带浏览器、Node.js 与 Python 引擎，使用者无需安装开发环境。

## 下载

| 系统 | 文件 | 说明 |
| --- | --- | --- |
| macOS 13+ · Apple 芯片 | `XHS-Downloader-1.5.0-mac-arm64.dmg` | Mac 安装包 |
| macOS 13+ · Apple 芯片 | `XHS-Downloader-1.5.0-mac-arm64.zip` | 同版本应用压缩包 |
| macOS 13+ · Intel 芯片 | `XHS-Downloader-1.5.0-mac-x64.dmg` | Intel Mac 安装包 |
| macOS 13+ · Intel 芯片 | `XHS-Downloader-1.5.0-mac-x64.zip` | Intel Mac 应用压缩包 |
| Windows 10 / 11 · x64 | `XHS-Downloader-1.5.0-windows-x64-setup.exe` | 可选择安装位置 |
| Windows 10 / 11 · x64 | `XHS-Downloader-1.5.0-windows-x64-portable.exe` | 无需安装的便携版 |

下载后可使用附件 `SHA256SUMS.txt` 校验文件。以上六个安装包包含相应系统的独立运行环境；Mac Intel 安装包由对应原生 GitHub Actions 构建机生成。

## 新增功能

- 输入个人主页链接，完整收集当前账号可见的帖子列表，按笔记保存图片、实况 MP4、视频和文案。
- 自定义抓取间隔与随机等待，默认间隔为 10 秒，另加 0–3 秒随机等待。
- 支持暂停、继续、重启恢复、失败重试；恢复时校验文件大小与 SHA-256，跳过完整文件。
- 内置独立登录窗口，登录后显示“已登录 · 当前账号昵称”，会话保存在本机。
- 遇到登录或安全验证要求时暂停；只有取得明确的主页结束标记后，才认定列表完整。
- 等待图片、实况配对视频及普通视频数据加载完整，避免只保存封面或遗漏动态片段。

## 使用与验证

首次使用请在下载器自己的窗口登录小红书，选择保存文件夹后开始任务。Chrome、Codex 浏览器与下载器的会话互不共享。macOS 首次访问“下载”或“文稿”文件夹时，需要在系统提示中允许访问。

发布前通过 91 项 Node.js 测试与 19 项 Python 测试。GitHub Actions 的 Mac Apple 芯片、Mac Intel、Windows x64 三个平台均通过测试、内置 Python 原生验收与安装包构建。Mac Apple 芯片已验证独立应用启动、登录昵称和任务恢复；示例主页实际收集到 240 篇，图片、文案、实况 MP4 与普通视频样本已下载并校验。该结果不代表 240 篇已全部下载完成。

本版本安装包未配置 Apple 签名 / 公证或 Windows 代码签名，系统可能提示无法验证开发者。Windows 包已完成构建和归档完整性检查，尚未完成 Windows 真机安装与登录下载验收。

“全部下载”仅限当前账号可见且能够打开的帖子。私密、已删除或平台限制的内容无法保证下载；设置间隔也不能保证不触发平台验证。
