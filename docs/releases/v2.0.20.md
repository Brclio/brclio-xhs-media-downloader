# v2.0.20：桌面新布局与头像收藏

桌面客户端将单篇下载、制作实况和主页下载保留在左侧，账号与设备、会员权益、用户评价、VIP 交流群及学习资源移至右上角个人菜单。问题反馈与关于入口固定在侧栏底部。已有下载任务、表单内容、页面滚动、更新和登录流程继续保留。

网页与 Mac / Windows 的软件账号新增头像设置，包含 100 张通过内置 imagegen 逐张生成的头像。头像随账号保存，退出登录后恢复默认标识。完整提示词与素材记录保存在 `assets/avatars/prompts.json`，生成原图保存在本地忽略目录 `dist-desktop/avatar-originals/`，并额外归档到 `~/Pictures/Brclio Avatars/2026-10-12/`。

## 自定义头像与原图收藏

- 支持 JPG、PNG、WebP 和 GIF，单张原图上限为 100 MiB（104,857,600 字节）。像素尺寸超过浏览器处理范围的文件会提示重新导出。
- 原文件按原始字节分块上传，保留文件名、大小和 SHA-256。客户端另行生成居中裁剪的 256×256 静态 WebP，界面只加载压缩头像。
- 原图、收藏元数据和缩略图都存入现有 GitHub 私有数据仓库的独立头像目录；账号业务状态仅保存当前头像指针。无需开通新的存储服务。
- 用户上传前可看到原图收藏和管理员下载说明。管理后台的「头像收藏」分页展示压缩预览，下载原图时才签发短时凭据。更换头像后保留已完成收藏的历史原图。
- 未完成上传会过期清理；每账号同时最多 3 个未完成上传，每小时最多发起 6 次、每天最多 10 次自定义上传。内置头像选择不受此上传额度影响。

## 发布与验证

桌面发布工作流检查全部 100 张独立压缩素材、真实头像选择与上传、原图收藏下载，以及已有登录、会员、下载、更新和管理功能。安装包沿用三平台原生构建、安装替换及重新启动核验流程。具体正式发布和生产验证证据在完成上线后归档。

Android 保持独立版本 1.0.15，本版不改变 Android 原生布局或账号会话。
