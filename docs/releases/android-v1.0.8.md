# Android v1.0.8：会员原视频下载入口

2026 年 10 月 1 日更新。Android 独立版本为 `1.0.8`，`versionCode` 为 `10008`。

## 本次更新

- 检测到平台原视频时，单篇结果新增「下载无水印视频 · 会员」。仅包含原视频的笔记也能显示此入口。
- 点击后在系统浏览器打开网页版，带入完整笔记链接并保留签名参数。用户在网页版登录软件账号、验证会员资格后下载；打开页面不会自动解析或开始下载。
- Android 原生层继续处理普通视频下载，不保存网页软件账号会话。原视频的会员校验和下载由同源网页版完成，尚未提供应用内软件账号登录与原视频保存。
- 原生视频下载和预览拒绝旧接口暴露的原文件地址，并复核主地址、备份地址与每次重定向，避免绕过会员下载入口。
- 原图、实况素材、普通视频、ZIP、系统分享及在线更新继续使用现有功能。

平台原文件可能保留作者自行写入画面的水印。页面未公开原文件或上游限制访问时，不承诺能取得无水印视频。实际原文件、音轨与画面的核验范围见 [来源说明](../watermark-free-video.md)。

## 安装与校验

正式附件为 [Brclio-XHS-Android-1.0.8-release.apk](https://github.com/Brclio/brclio-xhs-media-downloader/releases/download/android-v1.0.8/Brclio-XHS-Android-1.0.8-release.apk)。沿用正式应用 ID `com.brclio.xhs` 和固定签名，直接覆盖原正式版，按系统提示安装；不要先卸载。

同名 `.apk.sha256` 与 `SHA256SUMS.txt` 提供校验值，`android-update.json` 记录源码提交、版本、签名证书和模拟器验收。debug 包使用独立应用 ID，不能替代正式升级验证。

## 验证与发布门槛

本地 Android 前端测试覆盖完整链接传递、会员浏览器入口、原视频独占结果及旧原文件地址过滤；Java JUnit 验证普通播放、原文件拒绝与重定向规则。390 像素界面检查确认会员入口可见且没有横向溢出，原生相关 Java 文件已完成编译检查。

正式签名包须通过 GitHub Actions 的前端测试、Java JUnit、lint、构建及签名核验；工作流额外要求新原视频与重定向 JUnit 实际执行且无跳过，再进入原有 Android 15 覆盖升级、离线推广页与系统二维码保存验收。全部通过后才公开 APK，检查报告与 JUnit XML 随工作流保存。

公开发布和真实设备安装以对应运行结果确认。系统浏览器接收链接、网页登录与完整会员原视频下载仍需在真实 Android 设备验证；前端测试及模拟器升级检查不代表该跨应用流程已完成。
