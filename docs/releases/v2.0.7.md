# v2.0.7：HEIC 实况导出与两文件直接下载

版本记录日期：2026 年 10 月 4 日（北京时间）。本次更新网页和 Mac / Windows 桌面客户端的实况制作功能。Android 保持 v1.0.11。

## 本次更新

- 实况制作默认导出 HEIC 照片与配对 MOV，可选择 JPEG + MOV。HEIC 由本机编码器生成，不是将 JPG 改扩展名。
- 制作完成后，可分别点击「下载 HEIC 照片」和「下载 MOV 动态」，或下载包含两者与 `README.txt` 的完整 ZIP。JPEG 选项下载 JPG 照片。
- 两文件共用 `Brclio-Live-<UUID>` 名称，内部也写入相同配对 UUID。完整实况需要保留照片与动态视频两个文件；同时导入 Mac「照片」后检查 LIVE 标记和动态播放，需要同步至 iPhone 时开启同一账号的 iCloud 照片。
- 原有图片、图片组、视频制作方式继续提供：输出 0.5–3 秒，可调整图片顺序、视频起点、封面时刻及保留声音或静音。取消制作或修改素材、设置、格式后，旧下载结果与临时资源会清除。
- HEIC 在独立 Worker 中通过 WebAssembly 版 libheif / Kvazaar 编码，素材在本机处理，无需上传至转换服务。画面来自 8 位 Canvas，不承诺保留源素材的 HDR 或 10 位信息。此次增加 HEIC 输出，不承诺 HEIC 源图片的读取；GIF 继续作为静态图片处理。
- 设备无法进行 HEIC 编码时明确提示，用户可选择 JPEG，不会自动替换导出格式。MOV 仍需要浏览器支持 H.264 编码，保留声音还需要 AAC 编码支持。

[Apple「照片」导出说明](https://support.apple.com/zh-cn/guide/photos/pht6e157c5f/mac)说明，导出未修改的实况原片会分别得到静态图片与视频。仅将 ZIP 下载或解压到手机「文件」不会自动存入照片图库；导入及识别由接收应用处理。详细操作、限制和本地处理方式见[实况制作说明](../live-photo-maker.md)。
