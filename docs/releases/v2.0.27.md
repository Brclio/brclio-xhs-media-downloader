## 本次更新

- **支付宝与微信统一开通**：在「账号与会员 → 开通会员」选择付款渠道，核对该渠道的套餐与金额后打开收银台。微信使用独立支付中心和服务端产品凭据；原支付宝在线渠道与历史订单继续沿用。
- **微信 Native 扫码**：在电脑或另一台设备显示付款二维码，再用手机微信扫一扫。当前手机付款也需要另一台设备配合；本版不提供微信 H5、JSAPI 或原生 App 支付。
- **移除人工购买入口**：原支付宝、微信人工收款码与「我已付款，提交核实」不再用于新会员购买。历史订单、已开通会员、剩余时长、永久会员与已有激活码兑换保留。
- **同一笔交易只入账一次**：微信回调、主动查单与历史人工补录共用交易唯一性检查，避免同一笔付款重复记账或重复顺延；金额、商品、账号及订单不匹配时拒绝开通。
- **恢复订单期间避免另建付款单**：启动或切回软件时先核实已保存的待付款订单。原订单查询尚未完成、结果不确定或记录保存失败时保留原单，不开放新建付款。

会员仅在服务端核实支付结果并持久保存后开通。浏览器回跳、二维码展示或客户端成功提示不会直接授予权益；重试和重复通知不会重复增加会员时长。已有未到期时长继续顺延，设备授权规则保持不变。

## 安装与使用

已安装的 v2.0.26 及更早 Mac / Windows 客户端需升级安装本版，才能获得新的统一开通入口和恢复保护。付款页返回网页不会更新旧程序，也不保证拉起客户端；付款后请主动切回软件查询状态。

正常覆盖升级沿用软件账号、主页任务与下载文件；不要删除账号或任务数据处理订单等待。Mac v1.8.3–v1.8.6 请使用完整 DMG 手动覆盖并打开。Mac 尚无 Developer ID 签名及公证，Windows 尚无发布者代码签名。

Android 保持 1.0.15，本版不发布新 APK。Android 现有账号及订单入口打开正式网站，浏览器页面随网站更新。
