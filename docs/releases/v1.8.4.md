## 本次更新

### 已发现的更新可以继续下载

- 已发现新版后，后续版本查询限流、断网或返回异常信息，不再把“立即更新／继续下载”变成只能“重新检查”。
- 保留原版本信息、可信安装包地址、校验信息和下载进度，直接下载该版本的发布附件，不要求先重新查询最新版本。
- 更新弹窗和关于页以轻提示说明“暂时无法检查更新版本，仍可下载已发现的版本”，下载按钮继续可用。

### 准确区分查询和下载错误

- 版本查询受限与文件下载受限分别提示；文件下载失败时保留下载重试入口。
- 不再把所有 HTTP 403 都误报为接口限流。
- 获取另一新版信息时，只有校验和进度检查都完成后才切换候选版本，避免说明、安装包和续传进度错配。
- 保留更新包断点续传、安装进度、自动重开和新版正常启动后清理旧客户端备份。

## 升级说明

此修复在安装 v1.8.4 后生效。旧客户端若已卡在“重新检查”，可通过本页安装包直接升级。

已发现版本的信息在当前应用进程内保留；重启应用后仍需成功获取版本信息，才能核对并恢复下载进度。文件下载服务本身发生限制或网络故障时，仍需重试下载。

正常升级沿用原账号、任务记录和已下载文件。下载任务在重开后仍需手动继续。Mac 手动从 Finder 拖放 DMG 应用仍需自行打开。

## 验证与说明

发布流水线在 Mac arm64、Mac x64 和 Windows x64 上执行测试、打包、安装包源码比对、内置 Python 与真实 Electron 验证，全部成功后才公开本版本。各平台构建提交与安装包 SHA-256 见附件 `build-evidence.json` 和 `SHA256SUMS.txt`。

Mac 使用完整 ad hoc 签名，尚无 Apple Developer ID 签名和公证；Windows 尚无发布者代码签名。Windows 覆盖安装交互仍需实机验收。
