## 本次修正

- **继续支付原订单**：先查询付款状态，再为当前账号恢复同一个业务订单的收银台。重启后只凭已保存的订单引用即可恢复，不会因再次打开付款页创建另一笔订单，也不保存收银台令牌。
- **重新下单选择套餐**：点击「重新下单」后实时核实原单仍未支付，成功清除本机待核实引用后恢复套餐选择并刷新报价。核对新报价、再次点击付款才会创建新订单。
- **已付款与不确定状态保留原单**：已付款、权益确认中、查单失败或本机记录保存失败时继续核实原订单；已观察到的付款结果不会被迟到的未支付响应覆盖。只有服务端确认订单、账号与功能权限刷新完成后才结束恢复流程。
- **账号与迟到响应保护**：退出、换号或已有更新的订单操作后，旧恢复响应不能重新打开收银台、覆盖新订单或恢复已经清除的本机引用。会员仍仅由验签并持久保存的付款通知开通，同一笔付款重复通知不会重复增加时长。

**重新下单不会关闭旧支付订单。请勿在新旧订单中重复付款。** 旧订单仍可在「我的全部订单」核实，后续有效付款继续按原订单金额与权益快照正常入账。
