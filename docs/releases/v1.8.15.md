## 本次更新

- **失败链接直接可见、可复制。** 每条失败记录显示完整笔记链接，保留链接中的签名参数；复制成功或失败都会显示提示。
- **一键转到单篇下载。** 自动切换页面并填入链接、聚焦输入框，清除上次解析结果；点击「开始解析」后即可继续下载。
- **保留批量任务进度。** 批量任务运行时也能复制链接或转到单篇下载；原有单项重试、重试全部失败继续保留。
- **避免覆盖正在处理的单篇笔记。** 单篇任务忙碌时会提示等待；长链接在窄窗口中自动换行。

## 升级方式

Mac v1.8.7 及后续版本可在「关于软件」检查更新并安装。Windows 可使用应用内更新或下载 setup 覆盖安装；便携版通过应用内更新后会转为安装版。

**Mac v1.8.3–v1.8.6 请使用完整 DMG 手动覆盖。** 等待现有安装结束，完全退出旧版后，将新版拖入原安装位置并选择替换，再手动打开。账号、任务记录和下载目录无需删除。

主安装包继续使用 `Brclio-XHS-版本号-系统-架构` 命名。保留供旧版自动更新使用的三个旧名兼容附件，内容与对应的新名安装包相同。

Mac 使用 ad hoc 签名，尚无 Apple Developer ID 签名及公证；Windows 尚无发布者代码签名。三平台构建、归档源码比对、内置运行环境与安装包校验结果见本版发布附件中的 `build-evidence.json` 与 `SHA256SUMS.txt`。
