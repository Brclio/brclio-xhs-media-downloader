## 本次更新

- **后台直接回复。** 管理员打开问题反馈详情即可发送答复，并查看用户的后续补充；回复与处理状态分别操作。
- **用户查看并继续交流。** 登录软件账号后，在「问题反馈 → 我的反馈」打开自己的问题，查看完整对话、回复数量和处理状态，刷新获取最新答复。
- **完整原文保存在 GitHub。** 新问题的标题、说明与双方回复保留换行、空格和原始文字，存入现有私有业务仓库。诊断日志继续按原规则脱敏。
- **失败后可重试。** 发送未获服务器确认时保留原文，同一请求重试不会重复追加消息。每次读取与回复均核对身份和反馈归属，用户只能访问自己的问题。
- **旧反馈继续使用。** 已提交的历史问题可以继续回复，尚未完成的旧版反馈可以续传；旧版本已经脱敏保存的文字无法恢复为原文。

每条回复最多 8000 字符。已解决或已关闭的问题仍可继续交流，发送回复不会自动改变处理状态。完整操作、频率限制和存储说明见 [反馈与诊断日志说明](../feedback-diagnostics.md)。

## 升级方式

Mac v1.8.7 及后续版本可在「关于软件」检查更新并安装。Windows 可使用应用内更新或下载 setup 覆盖安装；便携版通过应用内更新后会转为安装版。

**Mac v1.8.3–v1.8.6 请使用完整 DMG 手动覆盖。** 等待现有安装结束，完全退出旧版后，将新版拖入原安装位置并选择替换，再手动打开。账号、任务记录和下载目录无需删除。

主安装包继续使用 `Brclio-XHS-版本号-系统-架构` 命名。保留供旧版自动更新使用的三个旧名兼容附件，内容与对应的新名安装包相同。

Mac 使用 ad hoc 签名，尚无 Apple Developer ID 签名及公证；Windows 尚无发布者代码签名。三平台构建、归档源码比对、内置运行环境与安装包校验结果以本版发布工作流及附件中的 `build-evidence.json` 与 `SHA256SUMS.txt` 为准。
