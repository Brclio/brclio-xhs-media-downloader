# v1.6.3 · Brclio 小红书下载器

应用正式更名为 **Brclio 小红书下载器**。同步更新 Mac 应用名称、Windows 安装程序与快捷方式、应用窗口标题，以及网页和更新记录页的名称。

继续使用原有应用标识、登录会话和下载任务目录。主页下载的“序号-帖子名称”文件夹、失败重试和应用内更新功能保持可用。

## 安装与升级

| 系统 | 安装包 |
| --- | --- |
| Mac Apple 芯片，macOS 13+ | `XHS-Downloader-1.6.3-mac-arm64.dmg`（另附 ZIP） |
| Mac Intel 芯片，macOS 13+ | `XHS-Downloader-1.6.3-mac-x64.dmg`（另附 ZIP） |
| Windows 10/11 x64 | `XHS-Downloader-1.6.3-windows-x64-setup.exe` |
| Windows 便携版 | `XHS-Downloader-1.6.3-windows-x64-portable.exe` |

v1.6.1 / v1.6.2 用户可在应用内检查并下载本版，再点击“安装更新”。Windows 按安装向导完成；便携版内置更新会转为安装版。v1.5.0 用户需要从 Releases 手动下载安装。

**Mac 首次更名升级：** 将 DMG 中的“Brclio 小红书下载器”拖入“应用程序”后打开新版。由于名称改变，旧的“小红书媒体下载器.app”可能同时存在；确认新版正常后可移除旧应用。登录和任务仍使用原有数据目录，请勿清理应用数据。后续同名版本正常覆盖即可。

安装包内置运行环境，无需另装 Python、Node.js 或 Chrome。安装包仍未配置 Apple Developer ID / 公证或 Windows 可信代码签名。`SHA256SUMS.txt` 与 `build-evidence.json` 提供安装包完整性与构建验证记录。
