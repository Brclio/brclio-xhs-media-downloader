# Android v1.0.9

- 软件检查更新、应用内下载安装包时自动读取管理后台的更新网络配置，获取最新订阅并选择到 GitHub 延迟最低的可用节点；出口受限或连接失败时继续尝试下一节点。
- 支持后台管理多个订阅来源。订阅地址仅来自后台，安装包不预设默认链接；后台未配置或关闭时直连，后台暂时不可用时使用之前成功获取的管理员配置。
- 更新完成、取消、失败和应用退出时关闭更新代理；系统终止应用进程时自动终止组件。单篇解析、媒体下载及其它页面继续使用原有网络方式，应用不修改系统代理或创建 VPN。
- 保留 APK 校验、固定签名覆盖升级及手动浏览器下载入口。覆盖安装时请保留原应用，不要先卸载。

本版本支持 Android 8.0 及以上，正式应用 ID 为 `com.brclio.xhs`，`versionCode` 为 `10009`。正式发布附件必须通过签名、校验值与既有模拟器升级验收；更新网络验收还需使用线上后台配置。
