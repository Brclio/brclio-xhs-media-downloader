# Android v1.0.13：软件评价与订单入口

版本记录日期：2026 年 10 月 9 日（北京时间）。Android 正式客户端版本为 1.0.13，versionCode 为 10013。

## 本次更新

- 首页增加「软件评价与订单」，可查看用户评价或登录后查看当前软件账号的全部订单。
- 两个入口在系统浏览器打开正式网站；评价无需会员，每个软件账号仅限一次。软件账号登录、个人订单与评价由网站处理，Android 不接收或传递账号凭据。
- 解析或保存期间避免跳出客户端；外部浏览器不可用时显示失败提示，可稍后重试。
- 正式入口只接受固定的评价/订单页面名，不传递账号参数。已有解析结果、下载、会员原视频和更新流程继续沿用。

本次与[桌面 v2.0.9](v2.0.9.md)及网页版同步。订单采用人工核实收款，历史待核实记录不自动计入后台营业额；详细规则见[软件评价、订单与营业额](../reviews-orders.md)。

## 安装

从官方 GitHub Releases 下载正式签名 APK，覆盖安装旧正式版即可。不要先卸载，以保留设置；Android 安装与打开仍需遵循系统确认流程。发布门禁包含 Java/Node 策略、真实页面与浏览器跳转、lint、签名校验及模拟器升级验证。
