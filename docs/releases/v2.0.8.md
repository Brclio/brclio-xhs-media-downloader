# v2.0.8：客户端大视频直接保存与实况素材改进

版本记录日期：2026 年 10 月 9 日（北京时间）。本次更新 Mac / Windows 桌面客户端的视频保存与本地实况制作，网页同步相关说明；同期 [Android v1.0.12](android-v1.0.12.md) 改进单独普通视频与实况 MP4 保存。两个客户端分别维护版本与发布通道。

## 本次更新

- 普通播放视频、会员无水印原视频和单独实况 MP4 在客户端持续写入本地文件，不再把完整视频合并到浏览器内存，也不再套用网页的 512 MB 固定上限。
- 主页批量视频移除原有 2 GiB 固定上限，沿用逐文件保存、任务暂停与恢复、已完成文件检查和失败重试。
- 大文件持续传输时不会仅因总下载时间较长而超时；连接持续无数据时仍会中断并报告错误。下载显示实际字节进度，完成前检查响应与文件完整性，失败或取消后清理未完成文件。
- 会员原视频继续验证软件会员授权，地址通过加密下载凭据传递，保存前复查当前账号与会员权益；普通播放视频免费保存的规则保持不变。已开始且持续传输的原视频不会仅因凭据满 30 分钟而在完成时丢弃，新下载仍拒绝过期凭据。来源、跳转与媒体类型检查保留，不能将网页登录或会员验证失败转为无保护下载。
- 桌面「制作实况」移除视频素材的 150 MB 固定上限，只编码选中的 0.5–3 秒片段。HEIC + MOV、可选 JPEG + MOV、照片与 MOV 分别下载、完整 ZIP、片段封面和声音设置继续提供。
- Android v1.0.12 的单独普通视频与实况 MP4 移除 512 MB 固定上限，持续写入本地文件，并移除这两种保存方式的总下载时长限制；连接和无数据超时、取消、文件完整性与音轨检查继续保留。图片、预览与 ZIP 归档的原有保护继续生效，会员原视频仍在系统浏览器登录后下载。

## 适用范围与限制

桌面直接保存视频不设置固定文件大小上限，实际可保存大小仍取决于可用磁盘空间、文件系统、视频编码支持、链接有效期与网络。大文件保存不需要先在网页中生成整份视频 Blob。

网页版仍保留浏览器内存保护；网页普通视频的 512 MB 上限和实况制作视频素材的 150 MB 上限继续生效，Android 会员原视频沿用网页限制。各端图片素材、图片像素、短片段输出、ZIP 归档与 Android 预览继续保留原有保护；需要保存较大的实况动态素材时可使用客户端的单独 MP4 入口。此更新不将 ZIP 归档改为无限大小。
