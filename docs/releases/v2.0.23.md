# v2.0.23：在线付款暂停与恢复提示

本版完善 Brclio Pay 收款状态识别。暂停时显示明确原因并停用付款按钮；恢复后可刷新报价继续原付款请求，保留原请求编号、套餐和报价，避免重复创建订单。

本版已[正式发布](https://github.com/Brclio/brclio-xhs-media-downloader/releases/tag/v2.0.23)，6 个主安装包、3 个旧更新器兼容文件及校验清单、构建证据共 11 个附件均已公开。三平台原生安装升级和自动重启门禁、新旧更新器及公开下载核验通过，见[发布核验](https://github.com/Brclio/brclio-xhs-media-downloader/blob/main/docs/releases/v2.0.23-publication-verification.json)。

## 本版改进

- 商品目录分别识别套餐启用与在线收款状态。收款暂停时保留当前价格，展示暂停原因及人工扫码说明。
- 已有待确认付款请求也能刷新报价；恢复收款后继续原请求，原报价会明确标识。账号切换后迟到的响应不能打开旧收银台。
- 新订单在已知收款暂停时不会写入业务存储。下单时才发现暂停，后端只返回固定公开提示，不透传支付中心诊断。
- 既有订单查询、付款通知验签、持久化去重和会员顺延继续使用原流程。Android 保持 1.0.15，浏览器账号页随网站更新。
