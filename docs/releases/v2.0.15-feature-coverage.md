官网的入口是 **Pages**：普通静态文件直接提供，`/api/*` 和 `/admin*` 经 `APP` 服务绑定进入主 Worker `brclio-xhs-downloader`。主 Worker 提供 Node 引擎、媒体下载、账号、后台和健康检查；Python 路径再经 `PYTHON_API` 私有服务绑定进入 `brclio-xhs-python`。两个 Worker 分别承担现有 Node 与 Python 功能。

控制台显示“无活动路由”不能据此判断 Worker 未被使用。本项目的 Worker 配置未声明 zone 路由，官网通过 Pages 和服务绑定调用；Python Worker 明确关闭公开 `workers.dev` 与预览地址。当前主 Worker、Pages 和两套生产引擎都已有实际响应证据，绑定另经只读元数据比对确认保留。

**Python 不应删除。** 前一轮网页发布时 Python 运行时源码未变，因此当时没有重新发布；这一说明仅属于历史状态。随后两套 Worker 已发布 Cloudflare-only 调整与原生诊断，Python 更新版本为 `ed93abf4-e2a2-4111-b7ca-6eeaf7b81c88`。同一真实视频笔记在两引擎各一次匿名复验中均被上游重定向到验证码页，API 仍返回 422；问题已定位但未修复，尚未采用浏览器或人机协作方案。当前网页和客户端的 `/api/python_parse`、`/api/python_image`、`/api/python_video` 仍依赖私有 Python Worker，删除会破坏接口。历史入口与保留证据见上述 JSON；最新部署状态见[部署文档](../cloudflare-deployment.md)与[安全诊断](v2.0.15-cloudflare-only-diagnostics.json)。
