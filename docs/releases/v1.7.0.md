# v1.7.0 · Brclio 小红书下载器：账号与会员授权

新增软件账号、会员、激活码、设备绑定与独立管理员后台，保留原有下载、归档、任务恢复、失败重试和应用内更新功能。本版采用人工开通与发码，**没有接入支付系统**。

**默认权限变化：主页批量下载需要登录软件账号、有效会员及已授权设备；单篇笔记下载继续免费。** 会员到期或设备授权被撤销时，已有下载文件和任务记录不会被删除。

## 新增功能

- **邮箱验证码注册与登录**：首次验证自动创建账号；验证码默认 5 分钟有效、只能成功使用一次，并限制发送频率与失败尝试。
- **持续保持登录**：软件会话不设置固定自动到期时间，凭据由系统安全存储保护。主动退出会撤销会话；持续登录不等于永久会员，会员有效期由服务器判断。
- **普通用户、有效期会员、永久会员**：显示会员状态与准确到期时间。管理员可以开通、续期、缩短或取消权益，变更后用户刷新即可获取最新状态。
- **设备绑定与受控换机**：默认每个账号绑定一台设备，新设备不能自动替换旧设备。管理员解绑后，旧授权保持失效；重装或丢失设备密钥时，由管理员核对并单独批准指定的新密钥设备。
- **人工激活码管理**：支持永久会员码、指定天数码、批量生成、复制、CSV 导出及未使用码作废。兑换截止时间与会员时长分别设置；激活码只能兑换一次，网络重试不会重复增加时长，永久会员不会被时长码降级。
- **独立管理后台**：按邮箱或用户 ID 查询账号，管理会员、设备、激活码，查看操作原因与变更记录，以及邮件和 GitHub 存储服务状态。

软件账号登录与小红书浏览器登录分别显示。软件会员不能替代小红书登录；授权服务不会收集小红书 Cookie、下载内容或任务路径。业务数据保存在独立的 GitHub 私有仓库，后端继续沿用 Vercel。

## 安装与升级

| 系统 | 安装包 |
| --- | --- |
| Mac Apple 芯片，macOS 13+ | `XHS-Downloader-1.7.0-mac-arm64.dmg`（另附 ZIP） |
| Mac Intel 芯片，macOS 13+ | `XHS-Downloader-1.7.0-mac-x64.dmg`（另附 ZIP） |
| Windows 10/11 x64 | `XHS-Downloader-1.7.0-windows-x64-setup.exe` |
| Windows 便携版 | `XHS-Downloader-1.7.0-windows-x64-portable.exe` |

安装包内置完整运行环境，无需另装 Python、Node.js 或 Chrome。v1.6.1 及之后版本可以在应用内检查、下载并打开更新安装包；v1.5.0 用户需要手动下载安装。Windows 便携版的内置更新使用 setup 安装包，会转为安装版。

覆盖安装沿用原有应用标识和本机数据目录，请勿清理应用数据。软件账号为本版新增功能，首次使用需要验证邮箱。清空应用数据或系统凭据丢失后可能需要重新登录，已绑定设备名额不会因此释放。

**安装包未配置 Apple Developer ID 签名 / 公证或 Windows 发布者代码签名，可能出现系统安全提示。** `SHA256SUMS.txt` 与 `build-evidence.json` 用于核对文件完整性和构建来源，不代表代码签名或公证。

## 已验证范围与限制

自动测试、三平台原生 CI 的 Electron / 内置 Python 检查，以及 Mac Keychain / Windows DPAPI 下两个独立进程重开后的凭据保持均已验证。真实 Vercel、GitHub 私有仓库、Gmail SMTP 与管理员开通、调整、取消会员及测试码生成 / 作废路径已验证。

**尚未完成操作系统重启、实际安装向导与覆盖升级的人工验收，也未完成桌面安装包连接真实服务后的完整邮箱登录、激活兑换及设备撤销交互验收。** 相关业务并发和故障场景通过模拟测试；真实 GitHub 压力 / 灾难恢复及新一轮真实小红书完整主页下载未验收。不要将进程重开、静态包检查或模拟测试等同于这些验收。

详细边界见[账号系统验证记录](https://github.com/Brclio/brclio-xhs-media-downloader/blob/v1.7.0/docs/account-validation.md)，部署和管理员初始化见[账号系统说明](https://github.com/Brclio/brclio-xhs-media-downloader/blob/v1.7.0/docs/account-system.md)。
