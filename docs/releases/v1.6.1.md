# v1.6.1 · 下载命名、失败重试与应用更新

主页下载按 `001-帖子名称`、`002-帖子名称` 创建文件夹。序号按首次发现顺序固定，继续下载和失败重试不重新编号；兼容旧版以帖子 ID 命名的目录及已有文件记录。

- 失败帖子提供单条“重试”，也可重试全部失败项。成功帖子保留，下载间隔继续生效；正在运行的任务先暂停再重试。
- 应用内显示当前版本，可检查、下载最新正式版，显示下载进度，支持取消和重试，并校验安装包大小与 SHA-256。
- 点击“安装更新”并确认后，保存暂停中的任务，打开新版安装包并退出当前应用。Windows 按安装向导完成；Mac 在打开的 DMG 中拖入“应用程序”覆盖。
- 普通使用者仍然无需安装 Python、Node.js 或 Chrome。网页登录、单篇媒体下载和原有网页部署方式保持兼容。

## 升级说明

**v1.5.0 没有内置更新代码，需要先手动下载本版安装一次。** 从本版开始，可以在应用内发现和下载后续版本。

正常覆盖安装会继续使用原来的本机登录和任务目录；安装后需手动继续暂停的下载任务。Windows 便携版的内置更新使用 setup 安装包，会转为安装版，旧便携文件不自动替换。Mac 打开 DMG 后仍需手动确认覆盖，不提供静默安装。

当前安装包尚未配置 Apple Developer ID / 公证或 Windows 可信代码签名，系统仍可能提示无法验证开发者。SHA-256 完整性校验不等同于发布者代码签名。

## 构建验证

三个原生 CI 平台通过测试与 Electron 启动检查后，验证归档源码、版本、CPU 架构及内置 Python 实际运行，再发布六个安装包。`SHA256SUMS.txt` 提供最终安装包摘要；`build-evidence.json` 提供源码提交和各平台验证记录。发布步骤还会核对 GitHub 保存的附件摘要，避免发布不完整的更新。
