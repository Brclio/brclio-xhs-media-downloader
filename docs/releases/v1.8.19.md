## 本次更新

- 修复 Mac 更新提示“无法确认应用处理器架构”的问题：直接读取应用的 Mach-O 架构信息，更新准备与独立安装助手均不再依赖 Xcode、Command Line Tools 或 lipo。
- 继续检查应用身份、版本、处理器匹配和完整签名；新版完成启动后才清理旧版，安装或启动失败保留恢复流程。
- 如果旧版已经出现架构错误，请下载下方对应芯片的完整 DMG，退出旧版并在原位置覆盖一次。旧版自带的更新器不会因发布新版而自动修复，无需删除账号、任务或下载文件。

- 网页版「编程私教与书籍」使用与主页相同的品牌标识、七项导航、当前页面高亮和手机布局。
- Android 独立版本 [v1.0.3](android-v1.0.3.md) 恢复已下载 APK 的安装重试入口，避免网络检查失败或系统安装器暂时不可用时重复下载。

## 安装与更新

Mac 要求 macOS 13 或更新版本。当前采用完整 ad hoc 签名，尚无 Apple Developer ID 签名及公证；Windows 尚无发布者代码签名。请按系统提示操作。

若旧版本的应用内更新正常，可在「关于软件」检查更新。若出现上述架构错误，先等待正在进行的安装结束，再完全退出旧版，用完整 DMG 覆盖原应用并手动打开。不要删除账号数据或重置下载任务来处理安装问题。

每个平台安装包均内置 Python 后台。SHA256SUMS.txt 与 build-evidence.json 记录正式附件校验值及实际验证结果；旧版兼容附件与对应新名称安装包字节一致。
