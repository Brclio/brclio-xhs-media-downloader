## 从 v1.8.5 / v1.8.6 升级

**推荐使用完整 DMG 手动覆盖。** 这两个版本自带的旧更新助手可能让新版或恢复的旧版直接退出；正在运行的旧助手不会因为发布 v1.8.7 而改变。

1. 下载与 Mac 芯片匹配的 v1.8.7 完整 DMG。
2. 等待现有安装结束，暂停下载任务并完全退出旧版应用；任务记录会保留。
3. 打开 DMG，将应用拖入原安装位置（通常是“应用程序”），选择替换。
4. 从安装位置手动打开新版，确认“关于软件”显示 v1.8.7；需要时手动继续原下载任务。

新版已完整安装并打开后，后续更新才使用本版内置的修复。不要为此删除账号凭据、任务记录或下载目录。Windows 沿用安装向导，便携版更新会转为安装版。

## 本次更新

**Mac v1.8.5 / v1.8.6 用户请使用完整 DMG：等待当前安装结束，退出旧版后覆盖安装，再从安装位置手动打开。旧版内置安装助手不会随发布新版自动修复，首次升级请参照发布页的完整升级步骤。**

### 修复 Mac 新旧应用启动后直接退出

安装助手以 Node 模式运行，旧流程可能把 `ELECTRON_RUN_AS_NODE` 等助手环境传给图形应用，导致新版无法正常打开；失败后尝试恢复的旧版也可能受影响。本版在启动新版和恢复旧版时清理这类环境，保留助手自身需要的运行方式。

### 等待真实界面就绪，支持慢启动与页面重载

界面初始化超过原来的 10 秒或发生页面重载时，继续检查当前受信任主页面的真实就绪状态，不再丢失迟到的启动确认。只为未完成的安装或清理记录启用等待；关闭窗口或退出应用会取消。账号安全存储仍在后台初始化，钥匙串等待不阻挡主窗口。

### 安装助手持锁时有限重试清理

新版已就绪，但安装助手尚未释放锁时，清理最多额外重试两次，避免只能等下次启动才清理临时旧版。每次仍完整核对安装记录、应用身份、签名与目录归属；身份或签名等校验失败不会触发这类重试，也不会绕过保护删除文件。

### 改进安装进度与保留兼容性

安装进度窗口使用 macOS 正常事件循环，解决窗口显示后无法激活、鼠标点击关闭无响应的问题。关闭进度窗口只隐藏进度，不中断独立安装助手；安装成功后仍自动关闭。网页与单篇下载功能、Node.js / Python 两套引擎、软件账号、会员授权和任务数据继续兼容；应用标识及用户数据目录保持原值。新激活码继续以 `Brclio-` 开头，旧 `XHS-` 码仍可兑换。下载任务重开后仍需手动继续。

## 验证与说明

发布流水线检查 Mac arm64、Mac x64 和 Windows x64 的测试、打包、安装包源码比对与内置运行环境。本版回归包含新旧应用启动环境隔离、真实 Electron 界面延迟超过 10 秒并重载后的就绪确认、等待取消、安装锁超时后的有限重试和原生 ASAR 备份清理。

六个品牌安装包与三个旧名兼容包继续逐个核对 SHA-256；构建提交、平台信息和校验结果随 `build-evidence.json`、`SHA256SUMS.txt` 提供。具体结果以本版工作流和附件为准；这些自动检查不等于所有用户机器或 Windows 安装交互均已实机验收。

Mac 仍使用 ad hoc 临时签名，尚无 Apple Developer ID 签名及公证；更新或重装后仍可能要求钥匙串授权，密码通常是 Mac“登录”钥匙串密码。Windows 尚无发布者代码签名。
