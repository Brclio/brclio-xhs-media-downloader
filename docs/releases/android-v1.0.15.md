# Android v1.0.15：版本检测优先直连

版本记录日期：2026 年 10 月 10 日（北京时间）。Android 正式客户端版本为 1.0.15，versionCode 为 10015。

## 本次更新

- 启动自动检查及手动检查最新版先直连，首轮请求最多等待 8 秒。成功时不读取代理配置、不获取订阅、不测速，也不启动内置代理。
- 连接故障、超时、HTTP 403 / 429 或 5xx 服务器故障时，按现有系统代理、VPN、手动停用与后台配置规则回退。取消、无效版本信息、地址校验和 TLS 安全错误不启动代理回退。
- 内置代理启动后，等待已配置节点与更新分组全部加载，再开始测速；避免控制接口先就绪、节点尚未加载导致误报不可用。等待有总时限，取消仍会结束内核并清理临时配置。
- APK 下载、SHA-256 校验、稳定签名核验及系统安装器确认沿用原有流程；浏览器下载继续使用浏览器自己的网络。

同期桌面版本为 [v2.0.14](v2.0.14.md)，两个客户端分别维护版本号和发布通道。旧版需升级后才会采用直连优先策略。

## 安装与核验

从官方 GitHub Releases 下载正式签名 APK，覆盖安装旧正式版，不要先卸载。发布门禁包含 Java / Node 测试、lint、签名校验、内置代理运行时验证与 Android 15 模拟器覆盖升级。本机已通过 81 项 Java 测试、lint 与三种 ABI 打包；真实内核在隔离首轮失败夹具下完成版本查询、取消及进程退出清理。该夹具不代表正式 APK 安装，也不声称本机 GitHub 直连已成功；详见[本机验收](v2.0.14-local-verification.json)和[节点加载竞争修复](v2.0.14-readiness-race-verification.json)。CI、公开附件和正式 APK 设备结果在发布后附上；ADB 覆盖验收不等同于用户已经确认系统安装器或浏览器下载完成。
