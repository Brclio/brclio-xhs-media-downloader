# v2.0.9：用户评价、全部订单与后台营业额

版本记录日期：2026 年 10 月 9 日（北京时间）。网页版与 Mac / Windows 客户端新增软件评价、个人订单查询与后台实收营业额；同期 [Android v1.0.13](android-v1.0.13.md) 提供评价与订单的系统浏览器入口。

## 本次更新

- 网页首页与桌面侧栏展示用户评价、平均评分与分页。所有软件账号均可评价，无需会员；每个软件账号跨网页和客户端仅限发布一次。匿名昵称和脱敏正文公开，邮箱与账号编号不公开。
- 「账号与会员」增加「我的全部订单」，可分页查看当前账号全部记录。扫码付款后，在会员弹窗点击「我已付款，提交核实」；订单显示为待核实，不会自动扣款或开通会员。
- 后台增加「订单与营业额」，可筛选并查看全部订单、确认待核实收款及补录历史真实收款；要求真实流水号、实际金额、渠道、收款时间和原因，防止同一流水重复计入。
- 营业额以已确认收款的实收金额计算，按北京时间支持日期、套餐、渠道汇总。历史定向发码显示为待核实，赠送、发码与兑换不自动算营业额。
- 评价、付款核实与管理员入账支持幂等重试及事务并发校验。退出或切换账号清除个人订单并丢弃迟到响应，网页和桌面继续使用已有安全登录机制。

会员价格与人工扫码付款、邮件发码、兑换开通流程继续沿用。订单确认和会员发码分别处理，未记录的旧线下收款需管理员核实补录。详见[功能与统计口径](../reviews-orders.md)。

## 安装与更新

Mac Apple 芯片、Mac Intel 和 Windows x64 分别提供对应安装包与 SHA-256。Mac 使用完整应用临时签名，尚无 Apple Developer ID 签名及公证；Windows 尚无发布者代码签名。请从官方 GitHub Releases 下载，按系统提示安装或使用客户端更新。

发布门禁包含后端权限与并发、真实网页/桌面/后台界面、三平台打包、原有下载与实况制作回归、安装替换及更新器验收。构建和公开附件的验证结果随正式发布证据保存。
