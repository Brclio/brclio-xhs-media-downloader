# v2.0.36：客户端内微信扫码与自动会员结果

本版已发布（北京时间 2026-10-21），Mac Apple Silicon、Mac Intel 与 Windows x64 三平台原生构建和验收通过；11 个附件已公开，网站与后端已部署。见[操作审计](v2.0.36-operation-audit.json)。

微信付款二维码直接显示在「开通会员」窗口，用手机微信扫一扫即可付款，无需先打开浏览器或在浏览器登录软件账号。套餐、应付金额与会员账号同屏展示，后台自动查询当前订单。

服务端确认付款后立即收起二维码，继续核实业务订单并刷新账号、会员期限和两项功能权限，完成后在窗口显示会员结果。无需关闭窗口才能看到会员生效。二维码展示、扫码操作和客户端回跳都不能直接授予权益，重复通知和查单仍使用同一事务性幂等流程。

二维码仅属于当前已验证账号的订单，不保存到浏览器存储、软件订单缓存或业务仓库。付款、过期、退出、切换账号或失去会话验证时都会移除二维码。关闭后重新进入会继续查询原单；刷新二维码不会自动创建新单，网络失败时保留原单核实入口。窗口重新显示后即使首次查单失败，后续自动查询成功也会恢复当前账号的有效原订单码；隐藏前发出的旧响应不能直接恢复展示。

保留原在线支付宝、历史订单、已有会员时长、永久会员、激活码与设备授权规则。二维码暂不可用时，可由用户明确选择打开原收银台；不会自动打开浏览器。原人工收款码和「我已付款」入口继续移除。微信仍使用 Native 渠道，手机网页需要另一台设备展示后扫码，本版不增加 H5、JSAPI 或原生 App 支付。

二维码由随软件发布的 [Nayuki QR Code generator v1.8.0](https://github.com/nayuki/QR-Code-generator/releases/tag/v1.8.0) 在本地绘制，不请求第三方二维码图片服务。另将客户端使用的 YAML 解析库更新到 2.8.3，纳入已有订阅和安装包回归。

Mac / Windows 用户需升级并打开 v2.0.36，网站更新不会改变旧版客户端。Android 保持 1.0.15，本轮不发布新 APK。正常覆盖升级沿用账号、任务、下载文件和历史权益。Mac 当前仍使用 ad hoc 签名，尚无 Apple Developer ID 签名及公证；Windows 尚无发布者代码签名。

本轮不新增真实付款来验收，不把隔离测试或预下单称为实付。用户此前成功付款及会员权益保留，无需重复付款。
