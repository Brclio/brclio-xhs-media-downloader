# v1.8.21：编程私教与书籍页面内置到软件工作台

## 本次更新

- 点击侧栏「编程私教与书籍」，直接在软件主窗口内查看书籍、教学方向和微信咨询，不再打开独立窗口。
- 侧栏保持可用，可随时返回单篇下载、主页批量、账号与会员、问题反馈或关于软件。返回时保留已填写的链接、下载任务、结果和反馈草稿。
- 页面使用安装包内的书籍图片与微信二维码；切换页面保留浏览位置，点击「返回下载工具」回到之前的工作台页面。
- 保留二维码放大、关闭和保存功能，改善内置页面在不同窗口尺寸下的布局和键盘导航。
- 对旧入口和新窗口打开请求统一在主工作台内展示，避免再次弹出广告窗口。
