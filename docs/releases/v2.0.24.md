# v2.0.24：付款等待、权益刷新与订单恢复

本版补齐 Brclio Pay 付款后的客户端核实流程：订单创建后进入等待，切回软件立即查单，服务端确认后刷新账号和功能授权，重启后继续恢复原账号的待核实订单。

## 四项修正

- **订单等待**：保留原订单报价并自动查单。支付中心显示 PAID、但业务订单仍待通知确认时继续等待，不重复下单、不提前授予权益。自动查询有退避和 10 分钟窗口，之后可点击查询或切回软件继续。
- **切回立即查单**：原生窗口回焦、页面重新可见或恢复联网时立即核实原订单，多种事件共享同一个在飞请求。
- **刷新账号和功能权限**：只有业务订单确认后，才重新获取账号并远程核实主页批量和会员原视频授权。临时失败、坏签名或旧授权不会假装完成；设备限制继续按服务端规则执行，不自动启动或恢复下载任务。
- **重启恢复**：新建订单在打开收银台前写入现有系统加密凭据，仅保存账号与业务订单编号，按服务地址和账号隔离。重新启动并核实原账号后恢复查单；确认及刷新成功后才清除记录。收银台地址、fragment、付款 token 不持久化。

浏览器仅保存非认证订单引用；无法使用浏览器存储时明确提示只能在当前页面继续，关闭后需到原账号订单页核实。网页返回与浏览器后退继续核实，不把回跳参数当作付款证明。

## 安装与回跳边界

**已安装的 v2.0.22 及 v2.0.23 需要安装本版，才能获得新的等待和重启恢复流程。支付页返回网页不会更新本机旧程序，也不保证拉起桌面软件。付款后请主动切回新版软件核实。** 新版不能补写旧版从未保存的本机订单引用；既有订单和付款权益仍可登录原账号在订单页查看或刷新权益。

正常安装升级保留账号、任务和下载文件；Mac v1.8.3–v1.8.6 请使用完整 DMG 手动覆盖并打开。Mac 尚无 Developer ID 签名及公证，Windows 尚无发布者代码签名。Android 保持 1.0.15，浏览器账号页随网站更新。
