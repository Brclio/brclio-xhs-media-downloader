## 本次更新

- 网页提供独立「实况制作」入口，桌面在主窗口内增加「制作实况」页面。切换桌面页面后保留正在制作的内容；返回下载工具继续使用原有下载功能。
- 从本地选择一段可播放视频，或 1–12 张图片。图片可调整顺序、移除；单张图片可选择轻微推进或保持静止，多张图片按顺序均分时长。
- 时长可选 0.5–3 秒，默认 3 秒。视频起点与时长互相约束，封面位置限制在所选片段内；原视频声音默认保留，也可选择静音。
- 制作前可预览所选片段与封面，制作过程显示进度并可取消。更换素材或修改设置后清空旧结果，避免下载与当前设置不一致的文件。
- 输出同名 JPG 与 MOV，并写入 Apple 实况配对标识和封面时间元数据。下载 ZIP 同时包含中文 `README.txt` 导入说明。
- 素材总大小上限 150 MB，图片总像素上限 6400 万，输出长边最多 1440 像素且不放大小图。处理在本机完成，不把选中的素材上传服务器。

## 导入相册

1. 下载并解压 ZIP，保留同名 JPG 与 MOV。
2. 在 Mac「照片」选择「文件 → 导入」，同时选中这一对文件；导入后检查 LIVE 标记并播放确认。
3. 如需同步到 iPhone，在 Mac 与 iPhone 开启同一账号的 iCloud 照片并等待同步，再在手机相册长按确认。

将 ZIP 下载到手机「文件」不会自动存入相册或变成实况。此功能提供配对文件和 Mac 导入指引，手机原生导入与 iCloud 同步全流程仍需在对应设备验证。

## 能力与验证范围

网页需支持 WebCodecs 的 H.264 编码；保留声音还需要音频编码与片段音频读取能力。页面在制作前检查可用能力，不支持时给出提示；无法保留声音时需明确取消「保留视频声音」。视频还需能被当前设备解码；GIF 作为静态图片处理，保留原动画请先提供视频。

本轮已通过真实 Electron 渲染器的图片、图片组、视频裁剪、封面、音轨、取消、结果重置与实际 ZIP 下载解压验证，并核对 390 / 768 / 1440 宽度的网页、桌面本地协议页面及桌面嵌入页面。实际生成的 JPG + MOV 经过 Mac 系统 `PHLivePhoto` 原生识别验证，音轨独立解码核对了片段位置与内容。这些结果不代替 Windows 设备上的相册识别、手机原生导入或 iCloud 同步验收。

Mac arm64、Mac x64、Windows x64 已在各自原生环境通过 H.264 / AAC 编码、播放与音频内容验证，随后构建并发布正式安装包，构建源码为 `1b72241ba24b0fc14f43d93ee43d8004ea8e9d80`。生产网页已核对实况入口、文件资源摘要，以及图片、视频、声音与实际 ZIP 导出。证据见[三平台 CI](https://github.com/Brclio/brclio-xhs-media-downloader/actions/runs/37176396468)、[生产网页验证](https://github.com/Brclio/brclio-xhs-media-downloader/blob/main/docs/releases/v2.0.5-web-verification.json)和[公开发布核验](https://github.com/Brclio/brclio-xhs-media-downloader/blob/main/docs/releases/v2.0.5-publication-verification.json)。
