# v2.0.16：长任务本地授权与故障续传

修复主页批量下载在账号服务短暂故障后暂停、误提示“GitHub 存储访问失败”的问题。小红书图片和视频仍从小红书下载到本机；GitHub 只用于现有账号后端的业务数据，不保存用户下载的媒体。

## 本次改进

- 开始、继续和重试主页任务，以及开始会员视频解析或保存时，联网确认账号、会员和设备授权，取得服务器签发的本机授权凭证。逐篇、逐张和视频分块改为本地校验，减少账号服务请求。
- 账号服务断网、繁忙或存储暂时不可用时，有限重试后，只要已有本机凭证仍有效就继续下载。没有有效凭证时须联网确认授权；故障提示明确区分软件账号服务、小红书验证和会员权限。
- 主页长任务每秒检查本机授权；后台每 5 分钟同步授权状态。确认会员失效、设备撤销或本机退出账号后停止后续下载。已下载文件和任务记录保留，恢复时校验已有文件再继续。
- 会员视频解析与原生保存各在开始时远程检查；视频分块和发布前使用本地授权复核。传输期间授权失效时拒绝发布媒体，保留已有完整文件并清理临时文件。
- 发布前新增三平台源码清洁检查，缺少有效构建来源证明的安装包不能进入公开发布。

## 授权期限

每份本机凭证最长有效 24 小时，且不会超过会员到期时间。永久会员也需要定期联网续签。联网正常时，远程撤销在下一次后台同步确认后生效；持续离线时，已有凭证最多可用到其到期时间。客户端不能自行延长或签发授权。

完整启用本地授权需要账号服务器先部署对应签名配置，客户端固定公钥须与服务端匹配。旧服务器未启用签名时使用远程兼容流程；已使用签名授权的客户端拒绝降级为无签名授权。旧版客户端需安装本版才具备这些行为。普通单篇下载继续免费。配置与密钥轮换规则见[桌面授权说明](../desktop-entitlements.md)。

## 安装与核验

Mac Apple 芯片选择 `mac-arm64.dmg`，Intel 芯片选择 `mac-x64.dmg`；Windows 选择 `windows-x64-setup.exe` 或便携版。官方发布继续提供六个安装包、三个旧更新器兼容附件、SHA-256 清单和构建证明。本次桌面版本为 2.0.16，Android 独立版本保持 [1.0.15](android-v1.0.15.md)。

隔离集成验证覆盖 130 篇帖子、390 张图片，第 101 篇后账号存储故障仍完成下载；会员到期、后台撤销和续期后恢复均检查文件保留与避免重复下载。会员视频验证覆盖 40 次分块请求无额外远程授权，以及到期、退出和撤销时拒绝发布媒体。上述测试使用真实签名、客户端授权逻辑和文件写入，账号及媒体传输使用测试夹具；不等同于反馈用户 Windows 设备的实际验收。详见[本轮验证记录](2026-10-12-desktop-entitlement-validation.json)。

正式安装包须通过 Apple 芯片、Intel Mac、Windows x64 原生 CI、包内源码与公钥比对、旧版升级和自动重启验证后发布。Mac 沿用完整应用临时签名，尚无 Apple Developer ID 签名及公证；Windows 尚无发布者代码签名。
