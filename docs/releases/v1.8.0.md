# v1.8.0：桌面分页、问题反馈与下载修复

桌面版新增固定导航，可切换单篇下载、主页批量、软件账号、问题反馈和关于软件。任务列表在当前页面内滚动，切换页面保留输入和任务状态；网页版维持原布局。

## 下载与音频

- 兼容小红书新的笔记数据结构；详情数据不完整时，按原抓取间隔执行同一笔记的页面回退。仍遵守登录、验证码、访问限制和服务端会员授权。
- 普通视频在保存前检查实际 MP4 媒体内容与音轨，尝试有声候选流；缺音轨时给出明确错误。恢复旧任务时也检查已存视频，修复失败保留原文件。
- Live Photo 动态片段可能在源站就没有音轨，按原始媒体保存；不会伪造声音。
- 没有增加 ffmpeg 等最终用户依赖，内置 Node / Python 解析引擎仍随客户端安装。

## 反馈和日志

- 已登录用户可提交反馈，无需会员；独立问题页面支持复制与导出日志。
- 日志记录启动、页面导航、任务恢复、笔记读取、受限状态、请求失败/重试、媒体字节与音轨、账号服务状态、更新阶段等信息。过滤 Cookie、凭据、签名 URL 参数、私人本机路径和硬件标识，不上传媒体内容。
- 本地日志从本版本开始记录，轮转上限 **8MiB**。提交时包含当时全部保留记录，说明保留范围；超过上限的旧日志不能追溯恢复。
- 上传固定日志快照，按完整行分块校验；失败保留本机快照，提交相同内容可重试。账号切换时停止上传，防止反馈归属错误。
- 管理员后台新增反馈管理、全文查看、一键复制问题及日志、独立下载 NDJSON/TXT 日志、处理状态与审计记录。
- 数据仍仅存独立 GitHub 私有仓库；服务端配置、域名与邮件服务不变，无新增数据库或支付系统。部署步骤见 [反馈及诊断日志说明](../feedback-diagnostics.md)。

## 更新

- “关于软件”和 Mac 应用菜单可主动检查更新；启动后、每四小时及长时间离开后返回应用会自动检查，提示新版本，安装仍由用户点击确认。
- 只从本仓库正式 Release 获取对应架构的安装包，校验下载长度与 SHA256，安装前再次校验。
- Mac 在可写安装目录准备新版、检查完整签名和架构，保存任务并退出后原位替换，保留旧版备份；失败时尽量自动恢复旧版。从 DMG、系统隔离或只读位置启动时需先移到“应用程序”或手动安装。
- Windows 使用下载安装向导覆盖安装；便携版转为安装版。用户无需安装开发环境。
- v1.7.1 及更早版本的 Mac 更新器仍会打开 DMG，需要手动拖入替换一次；安装 v1.8.0 后的后续更新才使用新的原位更新流程。

## 验证范围

- 发布前本机完整测试：**289 项 Node 测试通过、1 项原生更新组单独运行；21 项 Python 测试通过**。单独运行 Mac 更新测试 **16/16 通过**；安装包内 37 个应用源码文件与工作区逐字节一致，最终 DMG / ZIP 的完整签名与内置 Python 检查通过。
- **真实小红书与真实账号授权**：原 239 篇任务只重试编号 2、3、5，三篇均成功，分别保存 7、4、15 个文件。其余 236 条状态及所有文件夹编号未改变，任务保持暂停。
- **真实保存文件**：独立 ffprobe 检查得到两个普通视频均有 H264 + AAC 双声道；七个 Live Photo 源动态片段没有音轨。对其中一个普通视频另做短片段音量检测，存在正常音频信号。没有声称全部 239 篇或所有系统播放器都已验收。
- **本机真实 Electron**：验证主进程、隔离桥接、Node/Python 两种解析、五个页面、反馈交互、更新提示、长列表和窄窗口；系统安全存储跨两个应用进程保留身份。
- **反馈集成测试**：真实 API handler、GitHub 存储适配器和管理页，覆盖分块校验、完整复制/文件下载、角色与所有权、并发、断网、限流和丢失响应；故障注入与邮件采用模拟服务。另在正式域名提交 414,243 字节、两个分片的合成日志反馈，真实私有 GitHub 写入、整体确认及 begin/finalize 幂等重放成功。没有提交真实使用历史；生产管理员复制/下载与状态操作仍以本地集成测试为依据。
- **Mac 原位更新**：在本机临时签名应用和真实 DMG 中验证等待旧进程退出、替换及失败恢复；不等同于用户实际安装目录、系统重启或其他 Mac 的安全弹窗验收。
- **三平台产物**：发布工作流只有在 Apple 芯片、Intel Mac、Windows x64 均通过测试、打包和完整性检查后才发布。具体来源提交、签名种类和附件 SHA256 见本 Release 的 `build-evidence.json` 与 `SHA256SUMS.txt`。

Mac 使用完整 ad hoc 签名，尚无 Apple Developer ID 签名和公证；Windows 尚无发布者代码签名。外部 Mac 首次打开、Windows 安装向导及操作系统重启仍需对应机器人工验收。
