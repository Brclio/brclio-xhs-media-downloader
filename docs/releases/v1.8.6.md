## 本次更新

v1.8.6 是补丁版，汇总 v1.8.5 已有的 Mac 启动、临时旧版清理和激活码兼容修复，并纳入安装包构建与发布流程的修正。客户端功能与操作方式延续 v1.8.5。

### 继续包含 Mac 启动与清理修复

- 先显示主窗口，再异步读取钥匙串。拒绝授权后保留原凭据，可在软件账号页点击“重试安全存储”；系统缓存拒绝结果时需完全退出后重新打开。
- 更新助手等待新版窗口、页面和必要服务就绪，再确认安装完成并清理对应临时旧版。启动超时尝试恢复旧版，清理中断保留记录供重试。
- 新激活码使用 `Brclio-` 前缀，已发放的 `XHS-` 旧码继续可兑；兑换不区分大小写，并忽略首尾空白。激活码格式由账号服务提供。

### 修复发布流程的运行环境初始化

构建流水线先完成 Electron 运行环境初始化，再启动并行原生测试，避免多个测试同时下载、解压同一运行环境导致文件不完整。重新构建已有版本时，使用明确的远端版本标签，不会误取同名分支。

### 核对远端版本标签后再发布

创建发布草稿前，核对远端已有标签指向的提交与三平台构建证据一致；附件上传并核对摘要后，再检查一次标签，确认未被移动才公开发布。修正基于已有标签创建发布时的不必要权限要求，并保留已公开版本不可覆盖的保护。

六个品牌安装包和三个兼容包继续逐个核对 SHA-256；构建提交、平台信息与校验结果随 `build-evidence.json` 和 `SHA256SUMS.txt` 一起发布。

## 从旧版升级

已安装 v1.8.5 的用户可在“关于软件”检查并安装 v1.8.6，也可从本页下载安装包。正常覆盖安装继续使用原账号、任务记录和下载目录；下载任务在重开后仍需手动继续。

v1.8.3 / v1.8.4 仍由旧更新器执行首次升级，可能需要从“应用程序”手动打开新版。新版安装完成后，后续更新才使用已修复的完整启动确认与恢复流程。手动从 Finder 拖放 DMG 应用仍需自行打开；Windows 沿用安装向导，便携版更新会转为安装版。

Mac 钥匙串提示要求的是“登录”钥匙串密码（通常与 Mac 登录密码相同），不是邮箱密码或激活码。当前应用仍使用 ad hoc 签名，尚无 Apple Developer ID 签名及公证；更新或重装后仍可能要求系统授权。“始终允许”不能保证所有后续版本免提示。

## 验证与说明

发布流水线在 Mac arm64、Mac x64 和 Windows x64 上执行测试、打包、安装包源码比对、内置 Python 与真实 Electron 验证，全部成功后才公开本版本。具体构建提交和安装包 SHA-256 以本版附件为准；v1.8.5 的核验结果不替代本版产物检查。

Mac 系统钥匙串策略和外部设备安装表现仍以对应机器为准。Windows 尚无发布者代码签名，覆盖安装交互仍需实机验收；构建与自动测试不等于所有用户机器均已验收。
