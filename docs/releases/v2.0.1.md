# v2.0.1：清除小红书登录记录，方便切换账号

版本记录日期：2026 年 10 月 2 日（北京时间）。Mac / Windows 客户端新增「清除登录记录」按钮，清空客户端内的小红书登录信息后，可以重新登录其它小红书账号。

## 本次更新

- 在「登录小红书 / 完成验证」旁增加「清除登录记录」按钮，点击后通过系统确认窗口执行清除。
- 确认后暂停正在运行的主页任务，并关闭小红书登录与验证窗口，避免旧账号继续参与任务。
- 清除小红书专用会话中的 Cookie、登录资料、网站存储与缓存，以及相关的验证状态；清除完成后显示未登录，点击登录按钮即可切换账号。
- 已下载文件、主页任务记录及 Brclio 软件账号与会员权益保留。取消确认时保持现有登录状态。

本次更新仅涉及桌面客户端，Android 保持 v1.0.8。软件会员套餐继续使用日会员 3 元 / 1 天、月会员 19.9 元 / 30 天、年会员 69.9 元 / 365 天。

## 验证与发布门槛

发布前核验确认、取消、重复点击与任务暂停行为，检查小红书 Cookie、Local Storage、IndexedDB、缓存、Service Worker、HTTP 认证与连接状态的清除；同时验证清除后可重新登录、下载文件和任务记录保留，以及软件账号与会员状态保持可用。

Windows x64、Mac Apple Silicon 与 Mac Intel 必须分别完成安装包构建、完整包校验与升级验证，Mac 另需通过签名完整性检查。全部平台检查通过后公开发布 6 个正式安装附件、3 个自动更新兼容附件及 2 个校验与构建记录附件，再更新网页下载入口并核验线上版本。实际设备安装需在对应设备确认。
