## 本次调整

- Mac DMG / ZIP、Windows 安装版 / 便携版均使用简化后的文件名。
- 新版更新器优先选择新名称，继续识别历史发布的两种旧名称，并保留安装包来源、大小和 SHA-256 校验。
- 保留三个标记为“旧版自动更新兼容包”的旧名附件，供已安装的 v1.8.13 及更早客户端更新。它们与对应的新名安装包内容和校验值完全相同；手动下载请选择上方链接。
- 沿用应用身份、用户数据目录、账号会话和任务记录，以及 [v1.8.13](./v1.8.13.md) 的原生多图复制功能。安装包也包含新版产品介绍页与录屏演示模式。

## 升级方式

Mac v1.8.7 及后续版本可在“关于软件”检查更新并安装。Windows 可使用应用内更新或下载 setup 覆盖安装；便携版通过应用内更新后会转为安装版。

**Mac v1.8.3–v1.8.6 请使用完整 DMG 手动覆盖。** 等待现有安装结束，完全退出旧版后，将新版拖入原安装位置并选择替换，再手动打开。账号、任务记录和下载目录无需删除。

Mac 使用 ad hoc 签名，尚无 Apple Developer ID 签名及公证；Windows 尚无发布者代码签名。跨平台构建、源码比对、内置运行环境、安装包校验及原生功能验证由本版发布工作流执行，结果见发布附件中的 `build-evidence.json` 与 `SHA256SUMS.txt`。
