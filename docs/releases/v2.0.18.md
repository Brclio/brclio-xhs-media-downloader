# v2.0.18：Google 账号登录

网页和 Mac / Windows 客户端新增 Google 登录，保留邮箱验证码。首次登录可创建软件账号；符合邮箱关联条件的已有账号继续使用原会员权益、评价和订单。软件账号与用于读取笔记的小红书账号仍分别登录。

## 登录与设备

- 网页登录通过同源 HttpOnly Cookie 保存；完成回调时清除地址栏中的授权码与状态参数。
- Mac / Windows 在系统默认浏览器中登录 Google。页面显示账号邮箱和设备名称，用户明确确认后，客户端才取得本软件会话并保存至系统安全存储。Google 会话、授权码和轮询凭据不会交给客户端页面。
- 支持取消与超时重试；轮询遇到短暂网络或账号服务故障时，在原登录期限内每隔约 4 秒重试。退出或切换账号后，较早的 Google 登录结果不能恢复旧会话。设备名额、会员期限、设备撤销及下载授权规则沿用原有设置。
- Android 仍为独立版本 1.0.15。现有评价与订单入口打开系统浏览器，可使用网页 Google 登录；本次不新增 Android 原生软件账号会话。

## 安装与核验

桌面客户端需安装本版才会出现 Google 登录入口。正式分发继续使用 Mac Apple 芯片、Intel Mac、Windows x64 的原生构建及既有安装、升级、自动重启和包内源码核验流程。当前公开安装包仍为 v2.0.16，本版尚待正式构建与发布核验；不会替换已发布的旧版附件。v2.0.17 候选标签的原生 CI 未通过，未形成公开发行版；本版承接同一项 Google 登录更新。

本地隔离验证已通过 Google 客户端隔离测试，覆盖回调参数清理、浏览器 Cookie 写入顺序、失败退出保护、签名设备轮询、取消后的延迟响应、安全存储回滚、超时及地址校验。真实 Electron 页面验证已通过桌面取消、网页拒绝授权、网页登录、设备明确确认与拒绝确认五种场景，确认页和登录控件在 320px 宽度下无横向溢出。账号服务另有 Google 身份校验、Cookie 绑定和设备确认的隔离安全测试。

2026-10-12 已配置 Google OAuth 客户端和 Cloudflare Worker Secrets，并发布网页及后端。正式站的登录入口、Google 账号选择页及公开资源字节均已核验；用户已确认真实 Google 登录回跳后显示账号邮箱。浏览器控制工具在选账号后超时，因此该最终回跳证据来自用户确认。v2.0.17 Mac arm64 隔离预览包的完整临时签名、242 个包内源码比对、代理及 Python 运行时检查通过；真实 Google 登录、系统浏览器的设备确认、客户端成功提示以及重启后会话恢复均已核验，原会员、设备授权和下载任务保留。该预览证据保留其原始版本，不代表 v2.0.18 正式附件已通过核验。详见[本轮核验](v2.0.18-google-login-verification.json)。

v2.0.18 的三平台正式 CI 和公开安装包仍需分别取得证据。原应用包仍为 2.0.15，未被替换；实际登录验证使用隔离的 2.0.17 预览包，准备代码和启动预览不表示原安装已更新。

Mac 沿用完整应用临时签名，尚无 Apple Developer ID 签名及公证；Windows 尚无发布者代码签名。
