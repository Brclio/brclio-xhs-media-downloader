# v2.0.18：Google 账号登录

网页和 Mac / Windows 客户端现已支持 Google 账号登录，邮箱验证码登录继续可用。首次登录可创建软件账号；符合邮箱关联条件的已有账号继续使用原会员权益、评价和订单。

## 登录与设备

- 网页点击「使用 Google 账号登录」，完成 Google 授权后返回软件账号页。
- Mac / Windows 会打开系统默认浏览器。核对账号邮箱和设备名称，点击「确认登录此设备」后即可返回客户端，登录状态保存至系统安全存储。
- 保留已有会员、设备授权和下载任务；设备名额、会员期限、撤销及下载权限规则沿用原有设置。软件账号与用于读取笔记的小红书账号仍分别登录。
- 可取消 Google 登录，超时后重新发起。短暂网络或账号服务故障会在当前登录期限内自动重试；也可继续使用邮箱验证码。
- Android 仍为独立版本 1.0.15。现有评价与订单入口打开系统浏览器，可使用网页 Google 登录；本版不新增 Android 原生软件账号会话。

## 安装与核验

桌面客户端更新至 v2.0.18 后可使用 Google 登录。Mac Apple 芯片、Intel Mac、Windows x64 的正式安装包均已发布，并通过原生构建、安装升级、自动重启、包内源码及公开下载校验。Windows 同时提供安装版和便携版，旧版更新链接继续兼容。详见[正式发布核验](v2.0.18-publication-verification.json)。

Google 登录已验证网页回跳、客户端系统浏览器授权、明确设备确认、取消重试及重启后会话恢复；会员、设备授权和已有下载任务保留。登录与确认页面也通过 320px 宽度检查。详见[Google 登录核验](v2.0.18-google-login-verification.json)。

Mac 应用已通过完整临时签名校验，尚无 Apple Developer ID 签名及公证；Windows 尚无发布者代码签名。首次打开可能出现系统提示，请从官方发布页下载安装包。
