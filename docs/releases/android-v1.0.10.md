# Android v1.0.10：更新代理测试发布

本版与 v1.0.9 功能相同，仅递增版本号和 `versionCode`，供已安装 v1.0.9 的用户测试检查更新及应用内下载安装包的代理效果。

- 后台现有订阅配置保持不变，安装包不内置默认订阅。
- 检查更新、应用内下载安装包时使用后台最新配置，选择延迟最低的可用节点，用完关闭代理。
- 保留 APK 校验、固定签名覆盖升级和手动浏览器下载入口；其它功能保持不变。

支持 Android 8.0 及以上，正式应用 ID 为 `com.brclio.xhs`，`versionCode` 为 `10010`。请覆盖安装并保留原应用，不要先卸载。
