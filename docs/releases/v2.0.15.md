# v2.0.15：版本检测优先直连

发布于 2026 年 10 月 11 日 00:12:44（北京时间）。Mac / Windows 版本检测优先直连，降低内置更新代理的启动频率；同期 Android 独立版本 [v1.0.15](android-v1.0.15.md) 于 10 月 10 日发布。

## 本次改进

- 自动检查和手动检查最新版都先直连，首轮版本请求最多等待 8 秒。直连成功时不读取后台代理配置、不抓取订阅、不测速，也不启动内置代理内核。
- 连接失败、超时、HTTP 403 / 429 或临时服务器故障时，清理首轮连接，再按既有规则使用系统代理或后台启用的内置代理。内置代理仍按可用节点延迟排序切换，检查完成后关闭。
- 独立的直连超时不会取消后续代理请求；退出、取消以及较新的手动关闭操作仍然有效。无效版本信息、不可信地址、证书 / TLS 错误和本地缓存错误不会触发代理回退。
- 内置代理启动后，等待已配置节点与更新分组全部加载，再开始测速；避免控制接口先就绪、节点尚未加载导致误报不可用。等待有总时限，取消仍会结束内核并清理临时配置。
- 安装包下载、断点续传、内置代理下载自动重试以及安装并重启保持原有规则。版本检测不会自动下载或安装更新。

直连仅作用于版本请求，不修改系统代理、VPN 或其它业务会话。旧客户端需安装本版后才采用新的检测策略；本版发布前，旧客户端仍按自己的更新逻辑获取安装包。

桌面自动检测周期保持不变：启动约 5 秒后检查一次，此后每 4 小时检查；窗口重新获得焦点时，距离上次自动检查超过 1 小时则补查。

Mac Apple 芯片选择 `mac-arm64.dmg`，Intel 芯片选择 `mac-x64.dmg`；Windows 选择 `windows-x64-setup.exe` 或便携版。安装包及 SHA-256 清单由官方 GitHub Releases 提供，旧版更新器兼容附件继续保留。

[发布 CI](https://github.com/Brclio/brclio-xhs-media-downloader/actions/runs/38065548306) 的 Apple 芯片、Intel Mac、Windows x64 三个平台及发布任务全部通过，包含完整 Node / Python 回归、原生打包、替换与重启、回滚、Windows 安装版与便携版旧版升级、主进程桥接、原生剪贴板与内嵌页面验收。来源提交为 `5041d0e5df5208e116f17975d5c54462c9970322`。

公开发布核验通过 11 项附件、SHA-256 清单、构建证明、Latest 指向、9 个匿名安装包下载链接及旧更新器兼容性。独立核对官方 Apple 芯片 DMG 的完整字节、签名及 237 个包内源文件，临时目录启动和真实版本检测通过；直连成功，未启动代理，退出后进程已清理。

本机现有客户端通过软件内更新从 v2.0.7 下载、原位置替换并自动重启至 v2.0.15，“关于软件”显示当前已是最新版。启动检测约 1.1 秒直连成功，未启动内置代理，旧客户端备份自动清理。小红书登录与任务记录保留；后续复核确认系统安全存储已完成读取，软件账号与会员状态已恢复，验证过程中没有读取或输入用户密码。

网页已于 10 月 11 日发布到现有 Cloudflare 主 Worker 与 Pages，正式入口为 [软件下载](https://xhs.download.brclio.com/download)。该轮上线时生产匿名检查 58/58 通过；89 个公开文件在正式域名与 Worker 的 178 次字节及 SHA-256 比对全部一致，Pages 两入口的 6 次关键页面比对通过，4 个入口健康检查均确认 v2.0.15 与 Python 服务绑定。最初提供的真实公开笔记在 Node / Python 两套原生引擎均解析出 6 张图片，首图各下载 310,278 字节 JPEG，摘要完全一致；该笔记没有视频，当时未包含视频正向下载实测。这些结果属于后续诊断更新前的上线记录。

随后补测用户另提供的视频笔记：正式桌面客户端本地 Node 解析成功，但当时生产 Node / Python 解析均返回 422，旧 Vercel 备用地址返回 404 / `DEPLOYMENT_NOT_FOUND`，该笔记的线上完整流程未通过。通过正常来源页面取得的普通播放地址，在两套生产视频接口均完整下载 26,681,111 字节且 SHA-256 一致；Python 首次传输中断、一次完整重试成功，不能据此宣称生产笔记解析已恢复。上述失败保留为历史事实，恢复 Vercel 的早期建议已作废：正式托管继续只使用 Cloudflare。

后续两套 Worker 已发布移除外部解析回退与原生诊断，来源为 `76c0b02e59c82c6f63db658bc8d5b3121a451ddf`。主 Worker 版本 ID 为 `3f03b7ee-7261-4ce4-a4eb-636d94ac2298`，Python 版本 ID 为 `ed93abf4-e2a2-4111-b7ca-6eeaf7b81c88`；该轮匿名检查 58/58 通过，静态资源无需更新。同一真实视频笔记在两引擎各一次匿名复验中，都从笔记页 302 跳到验证码页 200，缺少当前笔记对象和媒体，API 仍返回 422。该次故障已定位为上游安全验证拦截，尚未修复，也未采用浏览器或人机协作方案。详见[安全诊断](v2.0.15-cloudflare-only-diagnostics.json)、[真实视频补测记录](v2.0.15-real-video-verification.json)与[Cloudflare 部署记录](../cloudflare-deployment.md)。
