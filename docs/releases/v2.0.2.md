# v2.0.2：后台管理的软件更新代理

版本记录日期：2026 年 10 月 2 日（北京时间）。Mac 与 Windows 客户端更新前读取管理后台的订阅设置，只有检查更新和下载软件安装包时启用内置代理。

## 本次更新

- 管理后台新增「更新网络」，支持保存、替换、删除或停用订阅。客户端下一次更新操作获取最新配置，无需重新安装软件来更换订阅。
- 软件不预设订阅链接。后台未配置或已停用时使用直连；后台暂时不可达时只使用此前缓存的管理员配置。
- 每次更新刷新后台指定的订阅，测量所有可用节点到更新服务器的延迟，优先选择最低延迟节点；单个来源失败时继续使用其它来源，出口受限时按测速顺序重试。
- 更新完成、失败、取消或退出后关闭内置代理。小红书解析、媒体下载、账号及其它功能保持原有网络方式，不修改系统代理或开启系统 VPN。
- 保留安装包 SHA256 校验与桌面断点续传。已经下载并校验的安装包在本地安装时无需启动代理。

Android 同期发布 v1.0.9，使用相同的后台订阅规则。
