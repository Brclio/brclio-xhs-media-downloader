# v2.0.14：版本检测优先直连

版本记录日期：2026 年 10 月 10 日（北京时间）。Mac / Windows 版本检测优先直连，降低内置更新代理的启动频率；同期 Android 发布独立版本 [v1.0.15](android-v1.0.15.md)。

## 本次改进

- 自动检查和手动检查最新版都先直连，首轮版本请求最多等待 8 秒。直连成功时不读取后台代理配置、不抓取订阅、不测速，也不启动内置代理内核。
- 连接失败、超时、HTTP 403 / 429 或临时服务器故障时，清理首轮连接，再按既有规则使用系统代理或后台启用的内置代理。内置代理仍按可用节点延迟排序切换，检查完成后关闭。
- 独立的直连超时不会取消后续代理请求；退出、取消以及较新的手动关闭操作仍然有效。无效版本信息、不可信地址、证书 / TLS 错误和本地缓存错误不会触发代理回退。
- 内置代理启动后，等待已配置节点与更新分组全部加载，再开始测速；避免控制接口先就绪、节点尚未加载导致误报不可用。等待有总时限，取消仍会结束内核并清理临时配置。
- 安装包下载、断点续传、内置代理下载自动重试以及安装并重启保持原有规则。版本检测不会自动下载或安装更新。

直连仅作用于版本请求，不修改系统代理、VPN 或其它业务会话。旧客户端需安装本版后才采用新的检测策略；本版发布前，旧客户端仍按自己的更新逻辑获取安装包。

## 安装与核验

Mac Apple 芯片选择 `mac-arm64.dmg`，Intel 芯片选择 `mac-x64.dmg`；Windows 选择 `windows-x64-setup.exe` 或便携版。安装包及 SHA-256 清单由官方 GitHub Releases 提供，旧版更新器兼容附件继续保留。

发布门禁覆盖完整 Node / Python 回归、两种 Mac 架构和 Windows x64 的原生打包与升级验收、真实更新界面、来源与运行时校验。Android 使用独立签名和模拟器升级门禁。本机已通过 1,168 项 Node 测试（另 12 项按条件跳过）、27 项 Python 测试、网页与 Pages 构建，以及真实 Electron 更新重试界面和主进程桥接。直连请求成功且未启动代理；隔离会话强制首轮断网后，使用真实后台配置、订阅和内置内核成功查询并完成清理。Electron 真实证书失败也已验证不触发代理回退。详见[本机验收记录](v2.0.14-local-verification.json)。Android 已通过 81 项 Java 测试、lint 与三种 ABI 打包验证；隔离 Android 15 模拟器中的真实内核回退、正常结束、取消及进程退出清理均通过，强制首轮直连失败明确标为测试夹具。代理加载竞争的来源与修复见[核验记录](v2.0.14-readiness-race-verification.json)。三平台 CI、公开附件和安装后结果在发布后附上。

Mac 沿用完整应用临时签名，尚无 Apple Developer ID 签名及公证；Windows 尚无发布者代码签名。Android 安装仍需按系统安装器提示确认。
