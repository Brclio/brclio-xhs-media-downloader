首页、更新记录页及桌面版的设计署名统一为 **© 2026 Brclio · CC BY-NC-SA 4.0**，设计链接指向 [Brclio 设计系统](https://github.com/Brclio/brclio-design-system)。同时同步源码中的设计版权说明与设计系统标记。

主页下载的“序号-帖子名称”文件夹、失败重试和应用内更新功能继续可用。

## 安装与升级

| 系统 | 安装包 |
| --- | --- |
| Mac Apple 芯片，macOS 13+ | `XHS-Downloader-1.6.2-mac-arm64.dmg`（另附 ZIP） |
| Mac Intel 芯片，macOS 13+ | `XHS-Downloader-1.6.2-mac-x64.dmg`（另附 ZIP） |
| Windows 10/11 x64 | `XHS-Downloader-1.6.2-windows-x64-setup.exe` |
| Windows 便携版 | `XHS-Downloader-1.6.2-windows-x64-portable.exe` |

v1.6.1 用户可在应用内检查并下载本版，再点击“安装更新”。Windows 按安装向导完成；Mac 打开 DMG 后，将新版拖入“应用程序”覆盖。v1.5.0 用户需要从 Releases 手动下载安装一次。

普通使用者无需安装 Python、Node.js 或 Chrome。正常覆盖安装保留本机登录和任务记录；暂停的任务需手动继续。Windows 便携版的内置更新使用 setup 安装包，会转为安装版。

安装包仍未配置 Apple Developer ID / 公证或 Windows 可信代码签名。随包提供 `SHA256SUMS.txt` 与 `build-evidence.json`，用于核对安装包完整性和三个平台的构建验证记录。
