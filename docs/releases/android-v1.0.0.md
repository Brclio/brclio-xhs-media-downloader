# Android v1.0.0：Brclio 小红书下载器

首个 Android 正式客户端，适用于 Android 8.0 及以上。Android 独立编号为 `1.0.0`，内部版本号为 `10000`；Mac / Windows 桌面版继续沿用原版本与更新通道。

## 单篇笔记下载

- 粘贴小红书笔记链接或完整分享文案，也可通过其他应用的系统分享直接传入文字。
- 解析标题、正文与图片，支持图片选择、原图保存、复制图片、分享图片、复制文案和媒体链接。
- 支持视频预览、可用清晰度选择和视频保存。
- 实况图片可保存原图、动态 MP4 或 JPG + MP4 素材 ZIP；勾选图片打包时附带对应实况片段与文案。
- 保存使用 Android 系统文件选择器；下载显示进度并支持取消，无需所有文件访问权限。

## 在线更新

应用启动后自动检查独立 Android 发布，也可在「软件更新」区手动检查。用户选择更新后，应用下载 APK 并核对校验值、包名、版本及签名，再进入系统安装确认。网络失败、取消或校验失败不会进入安装器。首次更新可能需要按系统提示允许 Brclio 安装应用。

## 安装与适用范围

下载本发布中的 `Brclio-XHS-Android-1.0.0-release.apk` 安装；同名 `.apk.sha256` 和 `SHA256SUMS.txt` 提供校验值，`android-update.json` 提供构建版本与签名证书指纹。正式包由固定 Android 密钥签名，后续正式版本可覆盖升级。此前的 debug 测试包使用独立应用 ID，不会被正式包覆盖。

笔记解析需要联网，下载受原笔记公开可见性与平台访问限制影响。当前 Android 版本提供单篇功能，不包含主页批量下载、小红书登录、软件账号或会员功能。下载期间请保持应用打开；实况 ZIP 为 JPG 与 MP4 素材，不含 Apple Photos 原生 Live Photo 元数据。多图粘贴效果取决于接收应用，也可使用系统分享或 ZIP。
