## 本次更新

- 应用版本正式升级为 **1.8.1**，重新构建 Apple 芯片 Mac、Intel Mac 和 Windows x64 客户端。
- 安装包统一以 `Brclio-XHS-Downloader` 开头，发布说明顶部提供直接下载链接，去掉正文重复标题。
- 更新器优先下载品牌安装包，也兼容旧版本文件名。附件中保留三个标为“旧版自动更新兼容包”的文件，供 v1.8.0 及更早客户端获取新版；手动安装请选择上方链接。
- 注册／登录验证码邮件底部新增编程私教介绍、微信 **Jiabcdefh**、新书《编程启蒙：思维与代码》推荐，以及中英文“这不是垃圾邮件”提示。验证码仍在首段，首次验证创建账号、5 分钟有效和只能使用一次的规则保持不变。
- 邮件内容由服务端统一提供，SMTP、Resend 和邮件网关适配器共享正文。服务端部署后旧客户端也会收到新版邮件，无需为邮件文案单独升级。

保留 [v1.8.0](https://github.com/Brclio/brclio-xhs-media-downloader/releases/tag/v1.8.0) 的桌面分页、问题反馈、诊断日志、下载修复、音轨检查及在线更新功能。正常覆盖升级继续沿用账号凭据、任务记录和已下载文件。

## 验证与说明

发布流水线须在三个目标平台完成测试、打包、安装包完整性检查、内置运行环境与真实 Electron 检查后，才会公开本版本。具体源码提交、构建验证和安装包 SHA256 见附件 `build-evidence.json` 与 `SHA256SUMS.txt`。

新增测试覆盖品牌安装包优先选择、旧名兼容、下载校验及三种邮件服务适配器的统一正文。邮件调用使用模拟服务，未将真实邮箱收件或垃圾邮件归类视为已验收；邮件文案不能保证服务商一定投递到收件箱。

Mac 使用完整 ad hoc 签名，尚无 Apple Developer ID 签名和公证；Windows 尚无发布者代码签名。外部 Mac 首次打开、Windows 安装向导及操作系统重启仍需对应机器人工验收。
