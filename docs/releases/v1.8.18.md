## 安装与更新

Mac 要求 macOS 13 或更新版本。当前采用完整 ad hoc 签名，尚无 Apple Developer ID 签名及公证；Windows 尚无发布者代码签名。请使用上方官方安装包，并按系统提示操作。

已安装用户可在「关于软件」中检查更新。Mac v1.8.3–v1.8.6 用户请等待旧安装结束，完全退出旧版，再用完整 DMG 替换安装并手动打开；无需删除账号、任务记录或已下载文件。

每个平台安装包均内置 Python 后台。发布附件包含 SHA256SUMS.txt 和 build-evidence.json；旧版自动更新兼容文件保持与对应新版安装包字节一致。
