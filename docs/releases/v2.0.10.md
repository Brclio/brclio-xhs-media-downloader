# v2.0.10：自定义昵称与评价正文规则修正

版本记录日期：2026 年 10 月 9 日（北京时间）。本次更新覆盖网页版与 Mac / Windows 桌面客户端。正式构建、公开附件、部署及安装验收的证据随发布记录补充。

## 本次更新

- 内置 1000 个不同昵称，没有自定义昵称的账号使用稳定的默认昵称。用户可随机换一个，也可自定义；公开评价使用昵称，不使用账号邮箱作为作者标识。
- 从「账号与会员 → 设置评论昵称」进入用户评价区修改昵称，已发表评价的用户也可修改，公开的历史评价显示当前昵称。每个软件账号仍仅可评价一次，发布后的评分与正文不可编辑。
- 评价正文仅将邮箱替换为 `[EMAIL]`，其余内容保留原文，按纯文本显示。手机号、微信号、链接与数字不再因通用诊断脱敏规则被替换。请自行决定愿意公开的内容。
- 昵称修改与评价发布沿用现有登录、账号校验、事务和请求编号重试机制。切换账号或退出后丢弃旧账号的迟到响应；旧昵称请求重试不会覆盖之后保存的新昵称。

旧版本已遮盖并保存的评价没有原文可恢复，本次不会还原这些文字。全部个人订单、人工核实收款及后台实收营业额继续按[既有业务规则](../reviews-orders.md)处理。

## 平台与兼容

Mac Apple 芯片、Mac Intel 与 Windows x64 发布 v2.0.10；网页部署相同昵称与评价规则。公开评价继续使用原有 `authorLabel` 字段，旧版客户端可以读取昵称与评价。

Android 继续沿用已发布的 [v1.0.13](android-v1.0.13.md)。客户端的固定系统浏览器入口直接打开正式网页，本轮没有 APK 实现变化，无需新 Android 包或版本号。

Mac 使用完整应用临时签名，尚无 Apple Developer ID 签名及公证；Windows 尚无发布者代码签名。桌面正式发布继续执行三个平台的完整打包、界面与安装升级门禁，并核验公开附件及校验记录。
