# v1.8.27：视频下载进度与状态反馈

本版桌面安装包未公开发布；修复后的正式版见 [v1.8.30](v1.8.30.md)。版本标签保持不变，以下保留构建说明。

## 本次更新

- 普通播放视频和会员无水印原视频在下载按钮附近显示专用进度面板；点击后立即反馈，会员验证与读取来源期间也能看到当前状态。
- 按实际接收字节更新进度条、百分比和已下载量，显示下载速度与耗时。等待网络响应时持续保留阶段与耗时，不使用模拟百分比。
- 接收、检查视频完整性、保存前验证会员和交给浏览器保存分别提示。下载完成或失败结果保留在下载区，重试时重新开始。
- 手机窄屏同样能就近查看进度。Android v1.0.8 的会员原视频入口打开网页版后自动使用本次改进，无需重新安装 Android 客户端。

无水印原视频继续要求有效软件会员。会员失效、退出或切换账号后不会保存原视频；重新登录也不会恢复之前的在途下载。作者写入画面的内容可能保留。

## 验证与发布门槛

真实 Electron 验收覆盖慢响应、接收字节增长、完成和失败状态保留、重试与实际 320 / 390 / 768 / 1440 像素视口，并保留未登录、非会员、会员到期、退出和同账号重新登录时阻止在途原视频保存的验证。

本地完整回归通过：Node 789 项（781 通过、8 项平台限定用例跳过）与 Python 27 项。已核验的用户原视频通过真实 Electron 页面、75 次 HTTP 分段和实际浏览器文件保存完成验收；文件 260,311,194 字节，保存前后 MD5 一致，观察到 107 次中间进度更新。会员与来源使用隔离的本地测试环境，本次未操作生产账号或重复抓取上游视频。

正式安装包须经过 Windows x64、Mac Apple Silicon 与 Mac Intel 的独立构建、完整包校验、签名完整性与升级检查。全部平台检查通过后公开发布，再更新网页下载入口并核验线上源码与接口。实际设备安装需在对应设备确认。
