## 本次更新

### 先显示窗口，再读取钥匙串

- 应用先打开主窗口，再异步读取系统安全存储；等待 macOS 钥匙串授权时，窗口仍可显示和响应。
- 软件账号页面显示读取进度。拒绝授权或解锁失败后保留原登录凭据，提供“重试安全存储”，不会自动删除凭据或创建另一套设备密钥。
- 系统可能缓存本次拒绝结果。如果解锁“登录”钥匙串后重试仍不可用，请完全退出应用再重新打开。

钥匙串提示用于允许应用读取加密密钥，保护本机的软件账号会话、设备密钥和浏览器登录信息。需要输入的是 Mac“登录”钥匙串密码（通常与 Mac 登录密码相同），不是邮箱密码或会员激活码。只有确认正在打开本项目应用时才允许访问。

当前 Mac 安装包仍使用 ad hoc 签名，尚无 Apple Developer ID 签名及公证。macOS 可能在更新或重装后再次要求访问钥匙串；“始终允许”不能保证不同版本永远免确认，本次修复也不取消系统安全授权。

### 确认新版实际启动后，再清理临时旧版

- 安装助手等待新版窗口、页面和必要服务就绪的确认，不再仅凭系统接受了“打开应用”请求就显示安装成功。
- 等待启动期间继续显示安装进度。新版未在规定时间内确认启动时，尝试停止对应新版进程并恢复旧版；无法安全恢复时保留恢复文件和失败记录。
- 修复 Electron 打包应用中临时旧版无法删除的问题。新版确认启动后核对安装记录和备份归属，再清理更新器创建的旧版备份；中断或清理失败保留记录供后续重试。
- 账号、任务记录、已下载文件和用户自行保留的其他应用副本不属于清理范围。

### 激活码统一使用 Brclio 前缀

新生成的激活码以 `Brclio-` 开头；已发放的 `XHS-` 旧码继续有效。兑换不区分大小写，并忽略首尾空白。此变更由账号服务发布后生效，已有客户端无需因激活码前缀单独升级。

## 从旧版升级

**v1.8.3 / v1.8.4 使用的是旧版更新器。** 首次升级到 v1.8.5 时，仍可能遇到旧版的启动或清理问题；安装完成后如软件没有自动打开，请从“应用程序”手动打开新版，必要时从本页下载 DMG 覆盖安装。本版更新器的完整启动确认与超时恢复流程，在安装 v1.8.5 后用于后续更新。

如果系统正在等待钥匙串授权，请先处理系统提示；拒绝后可在软件账号页重试，仍不可用时退出并重新打开。无需删除登录数据或卸载清空应用数据。

正常覆盖安装继续使用原账号、任务记录和下载目录；下载任务在重开后仍需手动继续。手动从 Finder 拖放 DMG 应用仍需自行打开软件。Windows 沿用安装向导，便携版更新会转为安装版。

## 验证与说明

发布流水线在 Mac arm64、Mac x64 和 Windows x64 上执行测试、打包、安装包源码比对、内置 Python 与真实 Electron 验证，全部成功后才公开本版本。各平台构建提交与安装包 SHA-256 见附件 `build-evidence.json` 和 `SHA256SUMS.txt`。

Mac 系统钥匙串策略、外部设备安装与启动仍以对应机器的实际表现为准；构建与自动测试不等于所有用户机器均已验收。Mac 尚无 Apple Developer ID 签名及公证，Windows 尚无发布者代码签名；Windows 覆盖安装交互仍需实机验收。
