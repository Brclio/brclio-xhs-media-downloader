# 会员开通与邮件发码

客户端入口：**账号与会员 → 开通会员**。客户先登录软件账号，选择套餐，使用微信或支付宝扫码付款，**付款备注必须填写软件账号邮箱**。管理员核实收款后发送激活码；客户在该邮箱收信，再回客户端兑换。

| 套餐 | 价格 | 会员时长 |
| --- | --- | --- |
| 日付 | 2 元 | 1 天 |
| 月付 | 9.9 元 | 30 天 |
| 年付 | 39.9 元 | 365 天 |

按次购买，不自动续费。兑换后生效，已有未到期时长会员会顺延。永久会员无需购买这些时长套餐。付款不会自动授予会员。

## 管理员操作

1. 在用户详情点击发码入口，或在“激活码”页查找并选择已注册的客户邮箱。
2. 核对付款备注和金额，选择套餐，填写操作原因。可选的“兑换截止时间”限制何时可兑换，与兑换后的会员时长分开。
3. 点击“生成激活码”，核对预览中的邮箱、套餐和有效期。
4. 点击“发送激活码至客户邮箱”。邮件包含激活码、套餐、会员时长和兑换说明。

发送状态表示邮件服务接受了请求，实际到达以客户邮箱为准。失败或结果待确认时重试原操作；刷新后也可从原记录继续发送。重试不会生成新激活码，已确认发送不会重复提交。SMTP 响应中断时可能收到相同激活码的重复邮件，但只能兑换一次。

指定邮箱的激活码只允许该软件账号兑换。原码不以明文保存到业务数据仓库；已有通用激活码、批量生成功能与旧 `XHS-` 激活码继续兼容。邮件复用现有配置，无需新增环境变量。

- `npm run desktop:verify:membership`：真实渲染器验证套餐、二维码加载、邮箱复制、登录与异常状态、窄屏布局和兑换衔接。
