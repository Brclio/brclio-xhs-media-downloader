# 原视频来源与水印核验

2026-10-01 使用用户提供、用户自有的视频笔记 `6ab9dad600000000140024ff` 做真实下载核验。该页在没有 Cookie 的普通页面请求中公开了当前笔记的完整媒体状态。公开状态的 JSON 字符串和 `\u002F` 转义属于序列化；该样本的原视频没有需要破解的内容加密。

## 页面中的两类视频

`video.media.stream.h264/h265` 是网页播放的转码流，有各自的尺寸、编码、音频信息、主地址、备份地址和签名参数。该样本网页播放流为 1280×720。转码流即便分辨率更高、`qualityType` 带有 `origin` 字样，也不能据此认定无水印。

`video.consumer.originVideoKey` 是当前笔记公开的原文件资源标识，该样本位于 `spectrum/…`。现有旧版 CDN 路径映射为 `https://sns-video-bd.xhscdn.com/<文档中实际给出的 key>`。程序只接受页面实际公开的值，不猜 key、修改签名或从推荐笔记取视频。若页面直接给出完整的 HTTPS CDN 地址，则保留其查询参数，不再把它当路径拼接。

现阶段原文件能力支持与公共播放流命名空间分开的 `spectrum/…` 和其他非 `/stream/` 原文件路径。公共播放通道使用 `/stream/`；如果页面把 `/stream/…` 同时声明为原文件，来源语义不明确，程序保守拒绝把它作为会员原文件候选，也不把同地址回退暴露为普通播放流或主媒体 meta。这里的路径区分只服务于权限边界，不是水印检测。

`video.mediaV2` 在该页是一个 JSON 编码字符串。内部 `video.width/height/duration/md5` 描述上传文件；内部 `stream` 描述转码流。本次下载原文件的 MD5 与页面声明的 MD5 完全相同，提供了原文件身份的额外证据。程序以 `metadataSource: "video.mediaV2.video"` 标明尺寸、时长和声明 MD5 的出处，不从播放流推断原文件的编码、大小或是否有音轨。

CDN 的普通 HEAD 响应虽然声明 `Accept-Ranges: none`，实际 GET `Range: bytes=0-0` 和 `bytes=0-3145727` 都返回 206，并给出正确的 `Content-Range`、长度与 `Accept-Ranges: bytes`。因此该样本可以通过严格校验的分块通道下载；不应仅凭 HEAD 的声明判定不支持 Range。

本次核验只证明这条实际下载样本的来源与抽样画面。其他笔记的 `originVideoKey` 仍是可核验的原文件候选，平台也可能收到作者自行上传的带水印文件。解析器统一保存 `sourceWatermark: "unknown"`，不将候选、最高分辨率或本次结果冒充对所有视频的自动水印检测。

## 程序合约与会员边界

内部解析结果将原文件候选放在 `originalVideos`，保留 `source: "origin-video-key"` 和确切的 `sourceField`。普通 `videos`、普通视频备份地址和实况图片视频中都排除与原文件相同的 URL。仅有原文件的笔记仍视为成功解析，桌面详情读取也支持这一情况。

公共解析响应只输出 `originalVideoCount` 和 `hasOriginalVideo`，不输出原文件地址。无水印下载通道需要服务器确认登录与有效会员资格，再从当前笔记重新解析和选择原文件；不能信任浏览器提交的任意原文件 URL。普通播放流继续走普通下载流程。具体鉴权、传输与平台适配由下载入口实现，不能只依靠隐藏按钮作为权限限制。

自动化回归覆盖目标笔记与推荐内容的隔离、原文件与播放/备份 URL 的隔离、完整签名 URL 保留、非法原文件字段、原文件独占笔记、`mediaV2` 元数据与损坏 JSON、桌面精确笔记快照及详情等待。Python Worker 解析内核从规范 Python 解析器生成，两者用同一组来源测试验证。

浏览器账号桥在切换账号或退出时立即撤回本地已验证权益，串行执行会写入 HttpOnly Cookie 的登录与退出请求，避免旧响应的 `Set-Cookie` 在新登录之后到达并替换账号。远端退出失败时保留本地退出状态；刷新先重试撤销，不会重新读取旧 Cookie 并恢复会员权益。

最终会员网关验收通过完整账号服务、账号 HTTP 边界和会员视频接口读取同一用户样本，75 个分段合并为 260,311,194 字节，MD5 再次与页面声明一致，并确认 H264 视频和 AAC 音轨。全过程进行了 156 次实时账号授权读取：成功请求在访问上游前及响应发送前各核对一次；访客、普通账号、持有票据的访客和会话撤销后的请求均在访问上游视频前被拒绝。账号与会员只存在于隔离测试内存，未修改线上账号或发送邮件。该结果验证代码与真实上游传输，不冒充线上会员账号或真实 Android 设备验收。

原视频元数据和分段结果先暂存，再核对同一账号、有效会员及票据时效，成功后才发送；上游请求等待期间发生会话撤销或会员到期时，不泄露视频字节，也不遗留视频响应长度。客户端订阅账号变化，在最后一次元数据请求后再次核对本地账号与会员；退出、切换账号或明确撤销权益会使本次在途下载持续失效，即使随后重新登录同一账号，也需重新发起下载。
